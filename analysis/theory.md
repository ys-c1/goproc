# 拉伸噪声的椭圆频谱与各向异性奈奎斯特采样

## 1. 约定

- 基础（各向同性）随机场 `b(p)`，`p = (u, v)` 为噪声坐标；
- 物理点 `x = (x, y)` 经坐标缩放送入噪声：`p = A x`，
  `A = diag(rX, rY)`，即 `u = rX·x, v = rY·y`；
- 本文实验取 `rX = 1, rY = r ≥ 1`：场在 y 方向被压缩，山脊（等值线拉长方向）沿 x；
- `f_b` 为基础场的带边频率（周/单位距离）。单层值噪声的能量集中在
  `|k| ≲ f_b` 内；多层 FBM 时 `f_b` 取最高八度的带边（见 §6）。

## 2. 频谱为什么是椭圆

设 `b(p)` 平稳、各向同性，功率谱密度为 `S_b(k)`，仅依赖 `|k|`。

拉伸场 `g(x) = b(Ax)`。由随机过程的尺度变换（变量替换 `p = Ax`，
`dx = det(A)⁻¹ dp`）：

```
R_g(τ) = E[g(x+τ)g(x)] = R_b(Aτ)
S_g(k) = ∫ R_b(Aτ) e^{-i2πk·τ} dτ
       = det(A)⁻¹ · S_b(A⁻ᵀk)
```

`A` 为对角阵时 `A⁻ᵀ = A⁻¹ = diag(1/rX, 1/rY)`，于是等功率谱轮廓
`S_g(k) = const` 等价于

```
S_b(kx/rX, ky/rY) = const  ⇔  (kx/rX)² + (ky/rY)² = c²
```

即 **频谱域椭圆**，半轴为 `rX·κ` 与 `rY·κ`（`κ = √c` 取在 S_b 的某等值面上）。

若 `S_b` 用高斯建模 `S_b(k) ∝ exp(−|k|²/(2σ₀²))`，则

```
S_g(k) ∝ exp(−kx²/(2(rXσ₀)²) − ky²/(2(rYσ₀)²))
```

频谱高斯宽度 `σkx = rXσ₀, σky = rYσ₀`，**长/短轴比 = max(r)/min(r) = r**。

### 空间域椭圆（对偶）

自相关 `R_g(τ) = R_b(Aτ)`。对高斯型 `R_b(τ) = exp(−|τ|²/(2λ₀²))`：

```
R_g(τ) ∝ exp(−τx²/(2(λ₀/rX)²) − τy²/(2(λ₀/rY)²))
```

空间相关宽度 `λx = λ₀/rX, λy = λ₀/rY`，y 方向（`rY = r`）是 **短轴**。
两个域的椭圆是傅里叶对偶，**长短轴互换，但长/短轴比同为 r**。

## 3. 短轴方向与局部频率（含术语澄清）

沿物理方向 `e` 的局部空间频率，由链式法则为方向导数的波数尺度：

```
f(e) = |Aᵀe| · f_b
```

- y 方向 `e = (0,1)`：`f_y = rY·f_b = r·f_b` —— 最高局部频率；
- x 方向 `e = (1,0)`：`f_x = rX·f_b = f_b`。

**关于“椭圆短轴方向对应更高局部频率”的准确表述：**

- 在**空间域相关椭圆**上，y 是短轴，该方向局部频率确实最高，
  `f_hi = r·f_b`，命题成立；
- 在**频谱域椭圆**上，高频方向（y）对应的是**长轴** `rσ₀`，不是短轴——
  傅里叶对偶把宽窄互换。两椭圆主轴方向一致、宽度互为倒数缩放，
  长/短轴比都等于 r。下文实测同时报告两个轴比，可交叉验证。

## 4. 沿短轴的奈奎斯特步长反解

奈奎斯特准则：采样频率 `fs ≥ 2 f_hi`，物理步长 `h = 1/fs`，
取等号即“刚好压在奈奎斯特边上”：

```
h_y = 1 / (2 f_y) = 1 / (2 r f_b)
h_x = 1 / (2 f_x) = 1 / (2 f_b)
```

边长 `L` 的物理域所需采样数：

```
N_y = ceil(L / h_y) = ceil(2 r f_b L),  N_x = ceil(2 f_b L)
```

朴素做法两轴都用 `h = 1/(2 f_b)`，在 y 方向欠采 r 倍，必然混叠；
单纯“全局加采样”若不沿短轴定向加密，要么浪费要么仍然不够。
代码实现：`internal/sampling/sampling.go`。

### 读数

1. **椭圆证实。** 频谱高斯宽度轴比 1.12/2.07/4.15/8.45，空间 1/e 相关
   宽度轴比 1.00/2.00/4.00/8.00，都贴着 r（频谱侧因值噪声不是严格
   带限、窗函数泄漏，偏差 2%–12%；空间侧在离散网格上精确）。
2. **频率乘积关系证实。** 实测短轴特征频率 0.325→0.636→1.253→2.539，
   严格按 r 倍翻番；其绝对值与 r·f_b 差一个固定常数 0.325，这是高斯
   二阶矩宽度（σ₀≈0.325 f_b）与“带边 f_b”两个定义的差，**比值律
   f_hi = r·f_b 本身精确成立**。
3. **奈奎斯特反解有效。** 修正网格的越界能量恒定在 0.02%（纯数值
   泄漏），细节相关 ρ 随 r 保持 0.92–0.97；朴素网格越界能量 3.6%–6.9%
   （混叠），ρ 在 r=4/8 崩到 0.51/0.24——这就是“细节糊成一片”的
   定量刻画，且加全局采样救不回来，因为欠采是方向性的。
4. r=2 时朴素网格尚未严重欠采（f_y=2 仅略高于 fs=2），两套网格差距
   很小，符合预期；差距从 r=4 开始拉开。

## 6. 多层 FBM 的推广

K 个八度、lacunarity=ℓ 时，第 i 层带边为 `f_b·ℓⁱ`，最高八度
`f_hi⁽⁰⁾ = f_b·ℓ^(K−1)`。各轴奈奎斯特步长按最高八度反解：

```
h_x = 1 / (2 rX f_b ℓ^(K−1)),  h_y = 1 / (2 rY f_b ℓ^(K−1))
```

即把本文公式中的 `f_b` 整体替换为最高八度带边；椭圆结论逐层成立，
总谱为各层椭圆谱的加权叠加，主轴方向不变。
