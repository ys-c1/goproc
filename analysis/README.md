# 摩尔纹（采样混叠）对照分析

## 结论先行

地形在某些缩放比下出现摩尔纹，根因是**采样混叠**：最高 FBM 层的主频超过
像素采样率的一半（Nyquist 频率），高频分量被折叠回基带，形成假纹路。

- 干净对照 **1:2**：主频/采样率 **r = 0.3200**（< 0.5，不混叠）
- 纹路对照 **1:8**：主频/采样率 **r = 1.2800**（> 0.5，混叠）
- 反解出的纹路比值区间：**r ∈ [0.5000, 1.2800] 周/像素**
  对应缩放比区间：**1:k ∈ [1:3.1250, 1:8.0000]**
- 区间内验证点 1:4（r=0.6400）：纹路像素 **7568**
- 区间外验证点 1:2.5（r=0.4000）：纹路像素 **709**（约为前者的 1/10.7）

## 量的定义（如何把缩放比落到代码参数上）

| 量 | 定义 | 取值 |
|---|---|---|
| 采样率 fs | 高度图每像素 1 个采样 | 1.0 采样/像素 |
| Nyquist | fs/2，可表示的最高频率 | 0.5 周/像素 |
| 缩放比 1:k | 拉远 k 倍，地形空间频率升 k 倍 | k ∈ [2, 8] |
| 基础频率 freq0 | 代码 `Options.Frequency = k × 0.02` | 0.02k |
| 主频 fm | 4 层 FBM、lacunarity=2 的最高层中心频率 | 0.02k·2³ = **0.16k** |
| 比值 r | 主频/采样率 | fm/fs = 0.16k |

最高层是第一个越过 Nyquist 的层（其下三层在 k≤8 时 r 分别为 0.02k、0.04k、
0.08k，均低于 0.5），所以用它的中心频率作主频。混叠后的表观频率按
`fold(f)=|((f+0.5) mod 1)−0.5|` 折叠，例如 r=1.28 折叠为 0.28 周/像素。

## 区间反解

混叠判据是采样定理：r > 0.5 即欠采样。

- 下界（临界缩放）：r = 0.5 ⇒ 0.16k = 0.5 ⇒ **k* = 3.1250**
- 上界：扫描范围最远端 1:8，r = 0.16×8 = **1.2800**

故纹路区间 r ∈ [0.5000, 1.2800]，对应 k ∈ [3.1250, 8.0000]。

## 纹路像素的计数口径

- 对每个内部像素（去掉最外圈，共 254×254 = 64516 个）计算 **3×3 邻域样本方差**；
- 阈值 T 取**干净对照 1:2 邻域方差的 99.9 分位 = 5.0816×10⁻³**，标定后全程固定；
- 方差 > T 记为一个纹路像素。

选 99.9 分位而非最大值：最大值受单个样本波动支配，高分位更稳；干净图自身
仅 0.10%（65 像素）越线，作为底噪可忽略。该阈值在三个不同种子下都给出
干净点恒为 65 像素，结论与种子无关。

## 三条独立证据互相印证

1. **计数曲线**（`artifacts/moire_analysis.png` 上半）：纹路像素随 k 单调上升，
   k=3.125→3.25 跨越 Nyquist 后持续放大，1:8 达 27393（42.46%）。
2. **FFT 倍频程分带**：最高 FBM 层在其原生频带的能量占比，k≤3.125 时为
   0.19–0.41%，k 一过 3.125 立即塌缩（0.141%），k≥4.5 后为 0——能量被折叠
   进基带。这是混叠的直接频谱证据，边界与理论 k*=3.125 精确吻合。
3. **4× 超采样基准**（盒滤波抗混叠）：直采与基准的 RMS 差从 0.0131（1:2）
   单调增至 0.0409（1:8），相关系数 0.997→0.967，差值正是被折叠的高频能量。

## 四点对照（seed=7，256×256）

| 角色 | 缩放比 | r | 混叠 | 折叠表观频率 | 纹路像素 | 占比 |
|---|---|---|---|---|---|---|
| 干净对照 | 1:2 | 0.3200 | 否 | 0.3200 | 65 | 0.10% |
| 区间外验证 | 1:2.5 | 0.4000 | 否 | 0.4000 | 709 | 1.10% |
| 区间内验证 | 1:4 | 0.6400 | 是 | 0.3600 | 7568 | 11.73% |

## 复现方法

```bash
# 1. 生成直采高度图（25 个缩放点，PGM + float64 原始数据）
go run ./analysis/genmap --size 256 --seed 7 --outdir artifacts/maps \
  --ks 2,2.25,2.5,2.75,3,3.125,3.25,3.5,3.75,4,4.25,4.5,4.75,5,5.25,5.5,5.75,6,6.25,6.5,6.75,7,7.25,7.5,7.75,8

# 2. 生成 4x 超采样抗混叠基准（11 个关键点）
go run ./analysis/genmap --ss 4 --outdir artifacts/maps_ss \
  --ks 2,2.5,2.75,3,3.125,3.25,3.5,4,5,6.25,8

# 3. 比值/计数分析（含密集扫描）
python3 -I analysis/analyze.py \
  --scan "2,2.25,2.5,2.75,3,3.125,3.25,3.5,3.75,4,4.25,4.5,4.75,5,5.25,5.5,5.75,6,6.25,6.5,6.75,7,7.25,7.5,7.75,8"

# 4. 方差分位数/超采样/分带能量诊断
python3 -I analysis/diagnose.py

# 5. 出图（matplotlib 在用户 site-packages，不能加 -I）
python3 analysis/plot.py
```

## 文件说明

- `analysis/genmap/main.go` — 批量生成器，`--ss N` 输出 N× 超采样盒滤波基准
- `analysis/analyze.py` — 主频/比值、固定阈值纹路计数、FFT 分带、密集扫描
- `analysis/diagnose.py` — 阈值余量、超采样 RMS、倍频程能量诊断
- `analysis/plot.py` — 两张分析图
- `artifacts/moire_analysis.png`、`artifacts/moire_spectrum.png` — 结论图
- `artifacts/maps/`（直采）、`artifacts/maps_ss/`（超采样基准）

## 工程含义

要在 1:k 缩放下不出现摩尔纹，需保证最高层主频低于 Nyquist：
`0.02k·2^(octaves−1) < 0.5`。可行手段：按缩放比动态截断 FBM 层数
（octaves ≤ ⌊log2(0.5/(0.02k))⌋+1），或在采样前做盒滤波/高斯预滤波
（即本分析的超采样基准方案）。
