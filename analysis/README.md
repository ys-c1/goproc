# 频率调高后规则条纹（混叠）分析

针对 `internal/noise`（smoothstep 值噪声）+ `internal/fbm`（多倍频叠加）的
采样混叠分析。结论与全部数字均由本目录脚本可复现。

## 0. 符号与采样模型

像素在整数坐标采样，格距 Δ（本项目导出时 Δ=1 像素），采样频率
f_s=1/Δ，**奈奎斯特 f_N=1/(2Δ)**。

值噪声把独立格点（格距 1/f₀，f₀ 为格点基频，单位 周期/像素）用
smoothstep 基函数 B 插值：

```
v(x) = Σ_i g_i B(f₀x − i),   B(u)= 1−fade(u)   u∈[0,1]
                              B(u)= fade(1+u)   u∈[−1,0]
```

`B` 紧支 [−1,1]，是分段五次多项式。其功率谱（维纳–辛钦）为

```
S_v(f) = (1/f₀) |B(f/f₀)|²
```

`B(f)` 由 `common.py` 用高分辨率 FFT 数值求，并经两条独立路径交叉验证：
基函数自相关的傅里叶变换、以及 4×10⁶ 格点纯 1D 值噪声的 Welch 周期图
（累计能量各阈值误差 <1%）。

## 1. 混叠能量与频率超出量成正比，是 ξ 与 Δ 的函数

离散采样把连续谱按 f_s 周期折叠。越过 f_N 的分量折叠进基带，成为
无法与真实低频区分的假频（即规则条纹的来源）。定义

```
频率超出量   ξ = max(f₀ − f_N, 0)
```

混叠能量（1D）即连续谱在奈奎斯特区之外的积分：

```
E_alias^1D(f₀,Δ) = ∫_{|f|>f_N} S_v(f) df          …（f₀>f_N 时非零）
```

**近阈值线性。** f₀=f_N+ξ 且 ξ≪f_N 时，积分下边界移动 ξ，被积函数在
f_N 邻域近似常数，于是

```
E_alias^1D ≈ 2 · S_v(f_N) · ξ = (2/f₀)|B(f_N/f₀)|² · ξ   ∝ ξ
```

即**混叠能量与频率超出量 ξ 成正比**。2D 方形奈奎斯特区由可分离性
（值噪声核在 x、y 独立）给出

```
E_alias^2D = 1 − (1 − E_alias^1D)² ≈ 2 E_alias^1D   （小量时）
```

**写成 ξ 与 Δ 的函数。** 令 q=f₀/f_N=2Δf₀，则 ξ=(q−1)f_N=(q−1)/(2Δ)。
代入得 E_alias 只依赖无量纲 q：等 q（即等 ξ·Δ）下，无论 Δ 取何值，
混叠分数相同——这就是 Δ 缩放：混叠由“超出奈奎斯特的相对程度”决定，
与格距本身无关。

实验一（`exp1_linearity.py`，65536 点 ×64 条独立 1D 序列，三档 Δ）：

| 关系 | 结果 |
|---|---|
| 近阈值线性 E1≈a·ξ（1<q≤1.5） | 实测/解析 R²≈0.87，斜率随 Δ 同比增大（a∝Δ，因 ξ∝1/Δ） |
| Δ 缩放（等 q 跨 Δ=2/4/8） | 实测 E1 极差/均值 ≤11%，解析严格相等（差 <0.1%） |
| 实测 vs 解析绝对水平 | 各 q 点一致（如 q=2：实测 0.093/0.093/0.089 vs 解析 0.104） |

## 2. 多倍频叠加：决定混叠的是最高层频率，不是基础频率

fBm 第 k 层（k=0..K−1）：

```
频率 f_k = f₀ L^k      振幅 a_k = G^k / Σ_j G^j     （L=lacunarity=2, G=gain=0.5）
```

各层独立，功率（能量）按振幅平方相加。第 k 层混叠能量为
a_k²·E2(f_k)，总混叠：

```
C_alias(f₀;K) = Σ_{k: f_k>f_N} a_k² · E2(f_k)
```

只有 **f_k>f_N 的层**贡献，且这些层里频率最高的 k=K−1（最高层）
f_top=f₀L^(K−1) 越界最远、其奈奎斯特尾最大。实验二（`exp2_dominant.py`）：

| K | f_top（细单位） | 总混叠 | 仅最高层 | 最高层占比 |
|---|---|---|---|---|
| 3 | 0.100 | 0.00075 | 0.00075 | **100%** |
| 4 | 0.200 | 0.00196 | 0.00130 | **67%** |
| 5 | 0.400 | 0.00238 | 0.00055 | 23%（K=5 有 3 层越界，最高层仍为单层最大之一） |

基础频率 f₀ 本身远低于 f_N，**不直接产生混叠**；混叠门槛由
f_top=f₀L^(K−1) 何时越过 f_N 决定。

## 3. 反解满足条纹阈值的基础频率上限

给定条纹对比度阈值 C*，求最大 f₀ 使 C_alias(f₀;K)≤C*。

**硬上限**（最高层格点频率不越界）：

```
f₀L^(K−1) ≤ f_N  ⇒  f₀_max^hard = f_N / L^(K−1)
```

**阈值反解**：对单调函数 C_alias 二分求根（`invert_f0`）。本项目参数下
C*=0.1% 时两者重合——因为最高层一旦越过 f_N，其振幅加权尾能量即刻
超过 0.1%。三档结果（像素当量，f_N=0.5/px、L=2）：

| K | 最高层 f_top（/px） | f₀ 上限（/px） | 反解上限（/px） |
|---|---|---|---|
| 3 | f₀·4  | 0.125 | 0.125 |
| 4 | f₀·8  | 0.0625 | 0.0625 |
| 5 | f₀·16 | 0.0312 | 0.0312 |

**层数越多，基础频率上限越低（每加一层减半）**，因为最高层频率随
L^(K−1) 增长。这解释了“同样调高频率，层数多的档位先出现条纹”。

## 4. 三档逐档比对与超限条纹周期

测试条件 f₀=0.2/px（三档最高层 0.8/1.6/3.2 均越 f_N=0.5），8 倍超采样
细网格作无混叠参考（`exp3_tiers.py`）。混叠分量折叠回基带的频率

```
f_a = fold(f_top) = ((f_top+f_N) mod f_s) − f_N ∈ [−f_N,f_N)
条纹周期 T = 1/|f_a|（像素）
```

| K | 最高层 f_top（/px） | 折叠 f_a（/px） | 条纹周期 T（px） | 解析 C | 实测 E2 | 超限 |
|---|---|---|---|---|---|---|
| 3 | 0.80 | 0.20 | **5.0** | 0.00075 | 0.00294 | 是 |
| 4 | 1.60 | 0.40 | **2.5** | 0.00196 | 0.00950 | 是 |
| 5 | 3.20 | 0.20 | **5.0** | 0.00238 | 0.01295 | 是 |

三档全部超限；K=4 的折叠分量最靠近奈奎斯特（f_a=0.4），周期最短
（2.5 px），其条纹最细密。预测周期以红线标在 `fig4_maps.png`。

**实测与解析的偏差说明（如实记录）。** 实测 E2 系统高于解析 C 约
4–6 倍，来源是 fBm 强低频层在奈奎斯特边界的频谱泄漏（2D 场低频能量
占绝对主导，分段窗的旁瓣把少量能量铺到带外）。证据：纯单倍频场走同一
Welch 流程时实测 E1=0.028 vs 解析 0.037，吻合良好；且扫描 f₀
（`exp3_sweep.py`/`fig5_sweep.png`）显示解析与实测**同序、同单调趋势、
阈值穿越点同量级**。解析公式本身可靠，偏差是有限窗口测量的正偏置。
