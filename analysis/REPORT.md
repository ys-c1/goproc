# 拉伸噪声主脊方向：理论证明与数值核验

## 0. 约定

- 坐标系：`x` 轴正东，`y` 轴向北（右手系）。**方向角以正东为 0°，逆时针为正**，无向脊线方向折叠到 `[0,180°)`。
- 拉伸用剪切实现。拉伸方向单位向量 `e1=(cosθ, sinθ)`，其法向 `e2=(-sinθ, cosθ)`；物理坐标 `p` 先旋转到局部系 `q=R(-θ)p`，施加剪切再转回：

  ```
  M = R(θ) · M_r · R(-θ),   M_r = [[1, r], [0, 1]]
  H(p) = N(M p)
  ```

  即沿拉伸方向的点不变，垂直方向的点被沿拉伸方向位移 `r` 倍。`r` 称为**轴比**，`θ` 为拉伸方向角。`N` 是各向同性值噪声 FBM。
- 实测主方向角：中心差分梯度 → **梯度模长加权**方向直方图（180 个 1° 桶，方向 mod π）→ 峰值桶三点抛物线亚桶插值。
- 对照估计器：结构张量 `E[∇H∇Hᵀ]` 主特征向量方向 + 相干性 `(λ1−λ2)/(λ1+λ2)`。
- 数据：512×512，种子 20261127，4 层 FBM（lacunarity 2、gain 0.5、frequency 0.02）。两组拉伸方向 `θ=0°`、`θ=35°`，每组轴比 `r∈{0.5,1,1.5,2,3}`，共 10 张。

---

## 1. 证明一：主脊方向角 = 拉伸方向角 + 轴比的反正切

**结论**

```
θ_ridge ≡ θ + atan(r)   (mod π)，折回 [0,180°)
偏移角 δ(r) = atan(r)
```

**推导。** 采样场 `H(p)=N(M p)`，由链式法则

```
∇H(p) = Mᵀ · ∇N(M p) = R(-θ)ᵀ · M_rᵀ · R(θ)ᵀ · ∇N(M p)
      = R(θ) · M_rᵀ · R(-θ) · ∇N(M p)
```

（用到旋转矩阵正交：`R(-θ)ᵀ=R(θ)`、`R(θ)ᵀ=R(-θ)`。）

第一步，在拉伸方向对齐坐标轴的局部系中考察。`N` 各向同性，其梯度没有统计意义上的优选方向；取一个梯度沿拉伸轴 `e1=(1,0)ᵀ` 的代表性结构（各向同性场内沿任意轴变化的结构统计等价，取 `e1` 不失一般性），即 `∇N = g·e1`。剪切对该梯度的作用为

```
M_rᵀ e1 = [[1,0],[r,1]] · (1,0)ᵀ = (1, r)ᵀ
```

变换后梯度向量的方位角

```
δ = atan2(r, 1) = atan(r)
```

**这个角只依赖轴比 `r`，与噪声取值、种子、场内容完全无关**，它就是剪切把拉伸轴梯度 `e1` 扳过去的偏移角。`r→0` 时 `δ→0`（不拉伸则不偏转），`r→∞` 时 `δ→90°`，单调性直观。

第二步，恢复整体朝向。局部系中的 `(1,r)ᵀ` 经 `R(θ)` 转回全局系：

```
∇H ∝ R(θ)(1,r)ᵀ
```

旋转只给方位角加 `θ`，故全局方位角为 `θ + atan(r)`。脊线方向作为无向轴 mod π，得到

```
θ_ridge ≡ θ + atan(r)  (mod 180°)
```

**证毕。** 该结论在 Go 侧有矩阵级单测固化：`internal/stretch/stretch_test.go` 的 `TestRidgeAngleFormula` 逐 `r` 断言 `M_rᵀe1=(1,r)` 的方位角等于 `atan(r)`，并断言旋转后等于 `θ+atan(r)`；`TestAgainstExplicitMatrix` 用显式 `R(θ)M_rR(-θ)` 矩阵逐元素核对 `Warp.Apply`。

> 约定说明：本报告按题目要求以**梯度主方向**（脊线法向）作为"主脊方向角"的观测量，它与公式 `θ+atan(r)` 同口径。若改用脊线切线方向，整体加 90° 即可，结论的可预判性不变。

### 1.1 一个必须讲清的区别：直方图峰值 ≠ 结构张量总体方向

梯度协方差 `E[∇H∇Hᵀ]=σ²MᵀM` 的主特征向量（结构张量的总体极限）方向是 `M_rᵀM_r=[[1,r],[r,1+r²]]` 的主特征方向，它在有限 `r` 下**不等于** `atan(r)`（如 r=1 时约 58.3°，而 `atan(1)=45°`），只在 `r→∞` 渐近重合。本文公式刻画的是"剪切把拉伸轴结构映射到的方向"（直方图模的收敛位置），不是二阶矩主轴。下文实测中结构张量在中等 `r` 的系统性残余偏差正源于此，这也说明在本公式口径下，**稳定后的直方图峰值比结构张量更对口**。

## 2. 证明二：该式可在生成前预判，无需目测

`θ_ridge = θ + atan(r)` 的右端只含两个**受控的拉伸参数**，不含任何场相关量（无种子、无噪声值、无像素）。因此给定 `(θ,r)` 即可在生成任何地图之前算出角度；唯一的前提是 `N` 各向同性，而值噪声 FBM 由格点置换构造、本身无定向分量。

各向同性前提的实测背书：`r=0`（不拉伸）基线的结构张量相干性仅 **0.072**（0 为完全各向同性），见 `artifacts/results/baseline_r0.json`。

**估计器真值自检（解析已知角）。** 先用脊角可解析求出的合成场验证"梯度加权直方图峰值"这套估计器确实能命中公式，而不是只会在真实噪声上碰运气：

```
H(x,y) = sin(3(x + r·y_north))   ⇒  ∇H ∝ (cos(·), r·cos(·))，梯度角恒为 atan(r)
```

| r | 直方图峰值 | 解析 atan(r) | 偏差 |
|---|---:|---:|---:|
| 0.5 | 26.50° | 26.57° | 0.07° |
| 1.0 | 45.44° | 45.00° | 0.44° |
| 2.0 | 63.50° | 63.43° | 0.07° |

最大偏差 0.44°（1° 桶 + 离散化），脚本 `analysis/synthetic_check.py` 可复现，证明估计器与公式同口径、可正确回收已知角。真实 FBM 的逐比核验见下节。

## 4. 偏差超过 5° 的逐条说明

共 5/10 个单图 case 超 5°，**全部表现为直方图峰值被钉在 90.5° 桶**。根因不是公式，而是弱各向异性下"1° 分箱 + 取 argmax"这一估计器的有限样本失稳，叠加值噪声引擎固有的格点各向异性：即使 `r=0` 完全不拉伸，0°/90°/180° 轴对齐桶的权重也达中位数的约 1.6–2.0 倍（`baseline_r0.json`）。当剪切诱导的定向还不够强时，这条天然竖直尖峰就会在 argmax 中压过真实脊峰。判据是相干性：失稳 case 的相干性都偏低（0.44–0.94），而稳定命中的 case 相干性 ≥0.93 或轴对齐于格点。

1. **A, r=0.5，偏差 63.94°（相干 0.44，最弱）。** 真实脊峰（26.6° 附近）权重只有中位的 7.75 倍，而竖直尖峰 15.56 倍，argmax 被劫持到 90.5°。8 种子集成直方图峰值 26.68°，距预判仅 0.11°——随机实现平均掉后公式精确成立。
2. **A, r=1.5，偏差 7.22°（相干 0.87）。** 峰落在 63.53° 而非 56.31°，是格点尖峰把 argmax 推偏约一个箱群；集成峰 56.16°，偏差 0.15°。
3. **B, r=0.5，偏差 28.94°（相干 0.48）。** 同样被竖直尖峰钉住，连结构张量（89.58°）都被拉向竖直，说明此强度下信号尚未压过引擎各向异性；属估计器失效区。
4. **B, r=1.0，偏差 10.50°（相干 0.74）。** 峰值 90.5°；集成平滑峰 100.0°、张量 92.8°，相对 80° 预判仍偏约 13–20°。旋转 35° 与正方格格点不可公度，每个旋转实现对格点各向异性的采样方式不同，集成难以像 θ=0 组那样干净平均，残余偏差更大；随 `r` 增大快速收敛。
5. **B, r=2.0，偏差 7.93°（相干 0.935）。** 相干性已很高，但 90.5° 的锐利格点尖峰仍在 1° argmax 中险胜。此时集成峰 103.58°（偏差 5.14°）、结构张量 103.76°（偏差 5.32°）两个独立估计器彼此吻合且都贴近 98.43° 预判，反证是单图 argmax 这个点估计离群，而非公式错误。

辅助证据——系统偏差随轴比单调衰减且与 θ 无关：结构张量偏差在两组里沿同一条曲线下降（A：28.6→13.8→6.8→3.6→0.58；B：28.0→14.4→8.3→5.3→3.58），说明这是引擎/格点的系统性离散化偏差，随剪切增强而消失；**θ=0 组的 8 种子集成直方图在全部 5 个轴比下偏差都 ≤0.27°**，是公式成立最直接的统计证据。

## 5. 结论

1. 数学上，剪切拉伸把拉伸轴梯度 `e1` 映射为 `(1,r)`，其方位角恰为 `atan(r)`；整体旋转 θ 后，**主脊方向角 `θ_ridge = θ + atan(r)`（mod 180°），偏移角即轴比的反正切**。该式只依赖 `(θ,r)`，可在生成前直接预判，无需生成后目测。
2. 工程上，公式在估计器稳定时被精确验证：单图中 A 组 r=1/2/3（偏差 0.53/0.14/0.57°）、B 组 r=1.5/3（0.81/2.80°）命中；θ=0 组 8 种子集成在全部轴比下偏差 ≤0.27°；合成解析场自检通过；Go/Python 双实现 262 万像素零差异。
3. 超 5° 的 5 个 case 全部源于弱各向异性下直方图 argmax 被值噪声引擎的格点竖直偏好劫持（峰钉在 90.5°），并有集成平均、结构张量、相干性三方证据排除公式错误。实践建议：预判直接用公式；若需在低轴比或旋转朝向下做经验确认，采用多种子集成直方图（或平滑/结构张量）估计，或把轴比提高到 r≥2（轴对齐）/ r≥3（旋转朝向）。
