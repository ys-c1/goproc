# 分层设色色带的面积与宽度预判：理论证明与数值验证

**对象**：`goproc` 生成的 128×128 归一化高度场（seed=7，octaves=4，频率 0.02，值域 [0,1]，格距取 1）。
**结论先行**：色带面积与平均宽度都能在出图前由同一组等值线积分预判；预判面积与逐层扫描实测在 8 带时全部落在 ±6% 内，16 带时仅两个极值带因格点太少超过一成，其余在 ±4% 内。

---

## 1. 记号与问题

设高度场为光滑函数 $u:\,D\to[0,1]$，$D$ 为平面区域。

- 高度 $h$ 的等值线（水平集）：$C_h=\{(x,y)\in D:u(x,y)=h\}$；
- 等值线欧氏总长：$\displaystyle L(h)=\oint_{C_h}\mathrm{d}s$；
- 高度落在 $[a,b)$ 的色带区域：$D_{a,b}=\{a\le u<b\}$，其面积 $A(a,b)=\mathrm{area}(D_{a,b})$；
- 梯度模 $|\nabla u|$，并定义**斜率加权等值线总长**
  $$\Lambda(h)=\oint_{C_h}\frac{\mathrm{d}s}{|\nabla u|}.$$

题目要求证明的命题是“等值面积对高度的导数等于该高度处等值线总长”。下面先给严格形式，再说明朴素形式何时逐字成立。

---

## 2. 证明一：$A'(h)$ 等于等值线总长（斜率加权形式，coarea 公式）

### 2.1 微元法（直观推导）

给高度一个微小增量 $\mathrm{d}h$，考虑厚度为 $\mathrm{d}h$ 的薄层
$D_{h,h+\mathrm{d}h}=\{h\le u<h+\mathrm{d}h\}$。

在等值线 $C_h$ 上取弧长微元 $\mathrm{d}s$。沿梯度方向（等值线法向）移动，高度变化与法向距离 $\mathrm{d}n$ 满足
$$\mathrm{d}h=|\nabla u|\,\mathrm{d}n
\quad\Longrightarrow\quad
\mathrm{d}n=\frac{\mathrm{d}h}{|\nabla u|}.$$
于是该弧元对应的薄层面积微元为
$$\mathrm{d}A=\mathrm{d}s\cdot\mathrm{d}n
=\frac{\mathrm{d}s}{|\nabla u|}\,\mathrm{d}h.$$
沿整条等值线积分得到薄层面积
$$\mathrm{d}A
=\left(\oint_{C_h}\frac{\mathrm{d}s}{|\nabla u|}\right)\mathrm{d}h
=\Lambda(h)\,\mathrm{d}h.$$
因此
$$\boxed{\,A'(h)=\frac{\mathrm{d}A}{\mathrm{d}h}
=\oint_{C_h}\frac{\mathrm{d}s}{|\nabla u|}=\Lambda(h).\,}$$

### 2.2 严格形式（coarea 公式）

对 Lipschitz 函数 $u$，余面积（coarea）公式给出
$$\int_D \varphi(x,y)\,|\nabla u|\,\mathrm{d}x\,\mathrm{d}y
=\int_{-\infty}^{+\infty}\left(\oint_{C_h}\varphi\,\mathrm{d}s\right)\mathrm{d}h.$$
取检验函数 $\varphi=1/|\nabla u|$（在 $|\nabla u|=0$ 的临界点处按极限处理，零测度不影响积分），左边化为
$$\int_D 1\,\mathrm{d}x\,\mathrm{d}y\ \text{在带内的部分},$$
即对任意 $[a,b]$，
$$A(a,b)=\mathrm{area}\{a\le u<b\}
=\int_a^b\left(\oint_{C_h}\frac{\mathrm{d}s}{|\nabla u|}\right)\mathrm{d}h
=\int_a^b\Lambda(h)\,\mathrm{d}h.$$
对上限 $b$ 求导即得 $A'(b)=\Lambda(b)$，与微元法一致。

### 2.3 色带面积的积分表达与朴素命题的成立条件

把 $[a,b]$ 切成高 $\mathrm{d}h$ 的微元薄层并求和：
$$\boxed{\,A(a,b)=\int_a^b\Lambda(h)\,\mathrm{d}h
=\int_a^b\!\!\oint_{C_h}\frac{\mathrm{d}s}{|\nabla u|}\,\mathrm{d}h.\,}$$

题目中“导数 = 等值线总长”的**朴素写法** $A'(h)=L(h)$ 只在
$$|\nabla u|\equiv 1$$
时逐字成立（此时 $\Lambda=L$）。一般地形坡度并不等于 1，必须保留 $1/|\nabla u|$ 因子。本数据的面加权平均坡度仅 $|\nabla u|\approx0.022$，$\Lambda/L$ 的中位数约 46；若直接用 $L$ 积分，面积会被低估约 **45 倍**（每带误差约 −98%，见 §6）。这正是必须区分 $L$ 与 $\Lambda$ 的原因。

> 离散视角的等价说法：若把“等值线总长”理解为在**高度度量**下、以 $\mathrm{d}s/|\nabla u|$ 为弧元的加权长度，则 $A'=\text{等值线总长}$ 对任意场严格成立。

---

## 3. 证明二：色带平均宽度 = 面积 ÷ 等值线总长

### 3.1 微元条带模型

把薄层 $D_{h,h+\mathrm{d}h}$ 看作由等值线 $C_h$ 沿法向平移 $\mathrm{d}n$ 扫出的“条带”。一条总长 $L$、法向宽 $w$ 的等宽条带，其面积为
$$\mathrm{d}A=L\cdot w.$$
由 $\mathrm{d}n=\mathrm{d}h/|\nabla u|$，高度 $\mathrm{d}h$ 对应的**几何法向宽度**沿等值线随坡度变化。对整条等值线取面积加权的平均宽度 $\bar w(h)$，仍满足条带恒等式
$$\mathrm{d}A=L(h)\,\bar w(h)\,\mathrm{d}h\ \text{（按高度微分）},$$
而由证明一 $\mathrm{d}A=\Lambda(h)\mathrm{d}h$，故瞬时平均宽度
$$\bar w(h)=\frac{\Lambda(h)}{L(h)}
=\frac{1}{L(h)}\oint_{C_h}\frac{\mathrm{d}s}{|\nabla u|}
=\left(\frac{1}{L}\oint\frac{\mathrm{d}s}{|\nabla u|}\right).$$

### 3.2 整条色带（有限高度区间）

对色带 $[a,b]$，定义带内平均欧氏等值线总长
$$\bar L_{a,b}=\frac{1}{b-a}\int_a^b L(h)\,\mathrm{d}h.$$
色带的**平均宽度**定义为带面积除以该带的等值线总长（条带面积 = 长 × 宽 的直接推论）：
$$\boxed{\,\bar W_{a,b}
=\frac{A(a,b)}{\bar L_{a,b}}
=\frac{\displaystyle\int_a^b\Lambda(h)\,\mathrm{d}h}
       {\displaystyle\frac{1}{b-a}\int_a^b L(h)\,\mathrm{d}h}.\,}$$

**这就是“两个量可由同一积分一起预判”的含义**：一次等值线扫描同时得到 $L(h)$ 与 $\Lambda(h)$ 两条曲线，
- 面积用 $\Lambda$ 的积分 $A=\int_a^b\Lambda\,\mathrm{d}h$；
- 宽度用同一批积分相除 $\bar W=A/\bar L$，其中 $\bar L=\frac1{b-a}\int_a^b L\,\mathrm{d}h$。

不需要为宽度再做一次独立测量。在 $|\nabla u|\equiv1$ 的特例下 $\Lambda=L$，于是 $\bar W=b-a$，即“宽度 = 高度区间厚度”，与直觉完全吻合。

## 4. 离散化与计算方法

连续证明落到 128×128 网格上的实现（代码见 `analysis/terrain_bands.py`）：

1. **三角剖分**：每个格网单元剖成两个直角等腰三角面（面积各 1/2），共 $2\cdot127^2=32258$ 面；每面内 $u$ 线性，梯度 $\nabla u$ 为常数。
2. **等值线长度（marching triangles）**：水平平面与三角面相交得一条线段。设孤立顶点与另两顶点高度差为 $\Delta_1,\Delta_2$，可由相似三角形得段长
   $$\ell(h)=\frac{2\,g\,w\,|h-h_{\rm iso}|}{|\Delta_1\Delta_2|},\quad g=|\nabla u|,\ w=\tfrac12,$$
   关于 $h$ 分段线性。所有面求和得 $L(h)$；乘以 $1/g$ 求和得 $\Lambda(h)$。
3. **预判积分（闭式解）**：每面的线性段在色带边切出的子区间上有解析积分，逐面累加得 $\int L\mathrm{d}h$ 与 $\int\Lambda\mathrm{d}h=A_{\rm pred}$，无采样误差。
4. **逐层扫描实测**：每个格点按高度归入色带，实测面积 = 带内格点数（每格点面积 1）。
5. **连通域（四邻域）**：纯 NumPy 并查集实现，对角接触不计为连通；记录每带连通域数与最大域面积。已与 scipy 的 `ndimage.label`（4 邻域结构元）在 200 组随机掩码上逐一核对一致。

**两套面积口径**：预判基于三角剖分连续域（面积 $(N-1)^2=16129$），实测基于 $N^2=16384$ 个单位格点（最外圈各差半格）。两者相差约 1.6%，是偏差的系统性来源之一。另用三角面**解析裁切面积**作为连续真值，与 $\int\Lambda\mathrm{d}h$ 的最大偏差为 $0$（机器精度，见 `integral_self_err` 列），证明积分实现本身精确闭合。

---

## 5. 预判流程（出图前即可完成）

1. 选定分层数 $K$（本文 $K=8$ 与 $K=16$），等高度边 $h_k=k/K$。
2. 对等值线做一次扫描，得到逐高度的 $L(h)$、$\Lambda(h)$。
3. 每带积分：$A_k=\int_{h_k}^{h_{k+1}}\Lambda\,\mathrm{d}h$，$\bar L_k=\frac1{\Delta h}\int L\,\mathrm{d}h$。
4. 宽度：$\bar W_k=A_k/\bar L_k$。
5. 出图后再做逐层扫描，与预判逐带比对，相对偏差超 10% 标 ⚠。

## 6. 数值结果与逐带比对

### 6.1 全局恒等式校验

| 校验项 | 数值 |
|---|---|
| 三角面数 | 32258 |
| 三角剖分域面积 $\int_0^1\Lambda\mathrm{d}h$ | 16129.0000000 |
| 8 带预判面积之和 | 16128.9999999（相对误差 $6\times10^{-13}$） |
| 16 带预判面积之和 | 16128.9999999 |
| 解析裁切 vs $\int\Lambda$ 最大带偏差 | 0（机器精度） |
| 面加权平均坡度 $\overline{|\nabla u|}$ | 0.0221 |
| $\Lambda/L$ 中位数 / 均值 | 46.3 / 49.5 |
| 朴素用 $\int L\mathrm{d}h$ 预测的总面积 | 356.1（低估 45.3 倍，每带约 −98%） |

coarea 恒等式在离散场上闭合到机器精度，验证了证明与实现的正确性；同时量化表明朴素 $L$ 公式在本数据上不可用，斜率加权因子不可或缺。

### 6.2 偏差汇总（阈值 ±10%）

- **8 带**：面积与宽度偏差全部在 $-5.75\%\sim-0.18\%$，**无超差带**。
- **16 带**：仅 **第 1 带（−11.33%）与第 16 带（−14.19%）超 10%**，均为顶/底极值带，实测格点仅 59、145 个，单格点量化相对权重太大；其余 14 带在 $-3.77\%\sim+0.34\%$。
- 宽度偏差与面积偏差**数值相同**：因为预判宽度与实测宽度共用同一个 $\bar L_k$，$\bar W=A/\bar L$ 中 $\bar L$ 被约去，这是“同一积分产出两个量”的必然结果，也是条带模型自洽的体现。
- 偏差主要为负（预判略小），来自连续三角域（16129）比格点计数域（16384）少最外圈半格，以及格点归带的量化；带越窄、格点越少，相对量化越显著。

## 附录 A：关键恒等式小结

$$
A'(h)=\Lambda(h)=\oint_{C_h}\frac{\mathrm{d}s}{|\nabla u|},
\qquad
A(a,b)=\int_a^b\Lambda(h)\,\mathrm{d}h,
$$
$$
\bar W_{a,b}=\frac{A(a,b)}{\bar L_{a,b}},
\qquad
\bar L_{a,b}=\frac1{b-a}\int_a^b L(h)\,\mathrm{d}h,
\qquad
L(h)=\oint_{C_h}\mathrm{d}s.
$$
当且仅当 $|\nabla u|\equiv1$ 时 $\Lambda=L$，此时 $A'=L$ 且 $\bar W=b-a$。

## 复现方式

```bash
# 1. 导出精确浮点高度场（Go 端，避免 PGM 8 位量化）
go run ./cmd/dumpheight --size 128 --seed 7 --octaves 4 \
  --out artifacts/data/height_s7_n128.bin
# 2. 核心恒等式自检（斜面/抛物面/随机场，机器精度闭合）
python3 -I analysis/selftest.py
# 3. 全量分析：出表、CSV、四张图
python3 analysis/run_analysis.py
# 4. 生成两栏 Markdown 表
python3 -I analysis/make_tables.py
```
