# 分层边界光晕外溢宽度的上界及其紧性

## 1. 问题与记号

高度分层边界是一条平面曲线，光晕加在边界外侧。局部坐标系取在边界的某个极值点：

- 原点为边界点，x 轴沿切线，y 轴沿外法向（光晕一侧为 +y）；
- 边界写成 `y = f(x)`，满足 `f(0)=0, f'(0)=0`；
- 光晕半径 r（像素），光晕 = 外侧到边界距离 ≤ r 的点集；
- 光晕外轮廓是边界沿外法向平移 r 的等距曲线（offset curve）：

```
g(x) = f(x) + r / sqrt(1 + f'(x)^2)        （外法向 n=(-f',1)/sqrt(1+f'^2) 的 y 分量）
```

直线边界下 `g(x) ≡ r`，光晕恰好占满一条宽 r 的带，外溢为 0。弯曲边界下外轮廓相对
切线参照线 `y=r` 抬升或下沉。**外溢宽度**用与光晕同宽的窗口 `|x| ≤ r` 上的二阶差分
度量：

```
w      = 2·(g(r) − r)              （双侧总外溢）
w_sag  = max_{|x|≤r} g(x) − r      （单侧最大外溢，矢高）
```

曲率按二阶差分估计（顶点 f'(0)=0，固定物理步长 h=1 像素，与栅格格距解耦）：

```
κ_est = ( f(h) − 2f(0) + f(−h) ) / h^3 ,   R_est = 1/|κ_est|
```

## 2. 上界：w/r ≤ r/R

**结论（外溢宽度上界）**：窗口 `|x|≤r` 内边界曲率半径满足 R_est ≥ R（即 |κ| ≤ 1/R）时，

```
w / r  ≤  r / R ,      等价地      w ≤ r²/R .
```

右侧 r/R 是无量纲比值，即“光晕半径与边界曲率半径之比”。

### 推导要点一：外轮廓的二阶导受曲率控制

用弧长 s 参数化边界，Frenet 公式给出单位切向 T、外法向 n 与曲率 κ：

```
T' = κ·n ,   n' = −κ·T .
```

等距曲线 G(s) = F(s) + r·n(s) 求导：

```
G'  = T + r·n' = (1 − rκ)·T ,
G'' = κ(1 − rκ)·n − rκ'·T .
```

其法向分量的量级为 κ（rκ≪1 时），即外轮廓在顶点附近的二阶导 `g″(0) ≈ κ(0)`。
窗口两端相对切线参照的矢高由二阶差分给出：

```
g(r) − g(0) ≈ ½·g″(0)·r² ≈ ½ κ r² ,
w = 2(g(r)−r) ≈ κ r²  ⇒  w/r ≈ rκ = r/R .
```

窗口内 |κ| ≤ 1/R 时二阶差分被同一常数界住，即 **w/r ≤ r/R**。

### 推导要点二：法向偏转只造成下沉，不造成额外抬升

外轮廓切向就是边界法向。边界切向从顶点转过的角度 θ(s)=∫κ ds，外轮廓平移向量
r·n(s) 的竖直分量为 r·cos θ ≤ r。法向偏转带来的竖直折损

```
r(1 − cos θ) ≈ ½ r θ² = O(r³κ²)
```

恒为非正贡献：它只让外轮廓相对 `y=r` 下沉。因此外溢的唯一来源是要点一的曲率二阶项；
直线（κ≡0）时两项皆为零，w 严格为 0，与零对照实验一致。把窗口内法向转角压小的构造
（曲率沿弧快速衰减）能减小折损，使实测比值向上界 r/R 靠拢。

## 3. 紧性：抛物线构造与坐标

取抛物线

```
f(x) = x² / (2R) .
```

- 顶点曲率 κ(0)=f″(0)/(1+f′(0)²)^{3/2}=1/R，曲率半径恰为 R；
- 曲率沿弧衰减：κ(x)=(1/R)·(1+x²/R²)^{−3/2}，|x| 增大时 κ→0；
- **令 R→∞（固定 r 即 r/R→0），顶点附近 κ→0，边界局部趋于直线**——这就是
  “让边界在局部曲率趋于零”的构造办法。

外轮廓解析形式：

```
g(x) = x²/(2R) + r / sqrt(1 + (x/R)²) .
```

窗口端 x=r 处做 r/R 的小量展开：

```
g(r) − r = r²/(2R) − ½ r³/R² + O((r/R)⁴) ,
w = r²/R · (1 − r/R + O((r/R)²)) .
```

于是

```
η ≜ (w/r)/(r/R) = wR/r² = 1 − r/R + O((r/R)²) → 1   (R→∞) .
```

η→1 即实测外溢与上界之比趋于 1，**上界紧**。脚本紧性表给出 r=4、r=8 两组半径下
R=8…1024 的 η：从 0.58/0.41 单调升到 0.996，全程 η<1（不越界）。

## 4. 数值验证（`glowspill.py`）

- 两组光晕半径 r=4、r=8；
- 三类边界：抛物线（紧界构造）、同顶点曲率的圆弧（常曲率、凸向光晕侧，外偏移等距线
  在窗口端下沉，w 恒负，无正向外溢）、严格直线（零对照，w=0）；
- 四套网格格距 1 / 0.5 / 0.25 / 0.1，主表取 r/R≤0.5 的工况；
- 曲率一律按二阶差分、固定 1 像素物理步长估计；
- 距离全部解析求解：圆弧用圆心连线交点，抛物线解驻点三次方程（卡尔达诺公式），
  直线为 |y|，并与密集网格参考交叉核对（零失配）。

### 栅格化的度量分叉（重要）

栅格按**竖直列**判定光晕、取最高光晕格心为列顶；而解析外轮廓是**法向**等距线。
强曲率下两者是不同对象：r=8、R=8（r/R=1）时栅格 wΔ=13.0 而法向等距线 wΔ=3.31。
只有近直线（r/R→0）时法向≈竖直，两种度量才合一。这正是上界在“局部曲率趋于零”处
被逼近的几何原因，脚本以“度量分叉对照”单列强曲率案例。

### 量化带与收敛

列顶是最高光晕格心，系统偏低至多一个格距 cell。近直线工况（r/R≤0.125）下逐列高度误差
（列顶−同列解析外轮廓）的均值稳定在约 −cell/2、最大绝对值 < cell，与直线零对照的
−cell/2 一致；格距从 1 缩到 0.1 时误差同比例缩小，验证向解析值收敛。粗网格当真实
w 小于一个格距时无法分辨，需细分网格。

### 可执行断言

`self_check()` 把四条结论固化为断言，运行即校验：
1. η 随 R 单调趋 1 且全程 <1（不越上界）；
2. 近直线工况逐列高度误差落在量化带内；
3. 直线外溢严格为 0，仅残留 −cell/2 量化偏差；
4. 圆弧解析 wΔ 恒负（无正向外溢）。
