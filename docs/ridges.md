# 山脊线判据：证明、修正与实测

本文对应任务书“先证明脊线落在曲率沿横截面取极小处，判别条件是 Hessian 两特征值的
符号与大小关系；再证明按该条件逐格判定得到的脊线一定连通成段，并把段数写成局部
极值点数的函数”。结论分三层：

1. 任务书的判别式 `λ₁<0 且 |λ₁|>|λ₂|` 可严格化简，但它不是脊线判据。按它逐格判定
   得到的是**区域**而不是曲线；这一层任务书的命题不成立。
2. 正确的脊线判据是 `∇f·e₁ = 0` 且 `λ₁<0`（e₁ 为 λ₁ 的特征向量）。按它提取，
   脊线确实连通成开链或闭环；但它**不会**“按逐格判定”得到，而要用等值线追踪。
3. 段数可以用极值点数写成**恒等式**。对任务书判据得到的是 Δf 的离散 Morse 关系
   `段数 = #(Δf<0 局部极小) − Σ(合并数−1)`；对高度图本身，上升脊弧数满足
   `弧数 = P + S − 1`（P 为严格局部极大点数，S 为鞍点数）。

下面逐条给出证明，再给两个画幅的实测。

## 1 记号与差分算子

网格 N×N，V[yN+x] 为第 y 行第 x 列。内部格点用二阶中心差分：

```
fx  = (f[x+1]-f[x-1])/2
fxx = f[x+1]-2f[x]+f[x-1]
fxy = 先沿 y 中心差分，再沿 x 中心差分
```

边界格点取双侧邻点会越界，因此另用单侧二阶模板（一阶导三点、二阶导四点）：

```
fx[0]  = (-3f[0]+4f[1]-f[2])/2
fxx[0] = 2f[0]-5f[1]+4f[2]-f[3]
```

实现见 `internal/diff`。下文一切“内部格点”的结论只用中心差分；边界格点单独标注，
不混入拓扑结论。

Hessian

```
H = [[fxx fxy],[fxy fyy]]
λ₁ ≤ λ₂ 为特征值，e₁ 为 λ₁ 的单位特征向量
```

二维实对称矩阵有闭式：

```
m = (fxx+fyy)/2,  d = (fxx−fyy)/2,  r = √(d²+fxy²)
λ₁ = m−r,  λ₂ = m+r
e₁ ∝ (fxy, λ₁−fxx)
```

## 2 曲率沿横截面取极小的含义

设曲线 Γ 为脊线，e₁ 为垂直脊线方向（横截面），则沿横截面的曲率为

```
κ_n = e₁ᵀ H e₁ = λ₁
```

“脊线落在曲率沿横截面取极小处”即要求 λ₁ 在 Γ 上取负的极小值。沿 Γ 参数 s，
一阶必要条件为

```
d/ds (e₁ᵀ H e₁) = 0
```

脊点若同时是临界点（∇f=0），上述条件与 `∇λ₁=0` 等价；但一般的脊点并不要求
∇f=0，此时“λ₁ 沿脊方向取极值”的正确微分表达就是 `∇λ₁` 与脊方向正交。
下面第 5 节给出的 `G=∇f·e₁` 正是这个条件在非临界点上的可计算形式：它要求
梯度沿横截面方向（∇f ∥ e₂），即沿脊方向 `∇λ₁` 的分量为 0。任务书想表达的
几何直觉是对的；但它把条件写成了“逐格比较 λ₁ 与 λ₂ 的符号和大小”，
漏掉了 `∇f·e₁=0` 这个真正的定位方程。下一节说明漏掉它会发生什么。

## 3 任务书判别式的化简（引理 1）

**引理 1.** 对实对称 2×2 矩阵 H，

```
λ₁<0 且 |λ₁|>|λ₂|   ⇔   fxx+fyy < 0        （即 Δf<0）
```

**证明.** 记 t=λ₁+λ₂=fxx+fyy，p=λ₁λ₂。

- 若 t<0。若 λ₁≥0，则 λ₂≥λ₁≥0，于是 t≥0，矛盾。故 λ₁<0。
  于是 λ₂>−λ₁≥0，即 λ₂=|λ₂|，且 |λ₁|=−λ₁<λ₂=|λ₂|。两部分同时成立。
- 若 λ₁<0 且 |λ₁|>|λ₂|。由 |λ₂|≥|λ₁| 当 λ₂≤0，故必有 λ₂>0。
  于是 |λ₂|=λ₂>−λ₁=|λ₁|，从而 t=λ₁+λ₂<0。∎

数值核对：在 20 万个随机对称矩阵上两条判据逐点一致；在两个 128×128 画幅上
`Mask` 与 `Δf<0` 逐格不一致数为 0（见 `internal/ridge` 测试与报告首行）。

**推论.** 任务书判据标记的是“净凹区域”，与脊线方向、梯度大小都无关。
它一半以上的格点会被标上（实测 49.7%–49.9%），不是一条线。

## 4 任务书“连通成段”命题不成立（反例）

取

```
f₁(x,y) = xy − 0.4(x²+y²)      在 [−1,1]²
f₂(x,y) = xy + 0.4(x²+y²)
```

Hessian 恒为 `[[−0.8,1],[1,−0.8]]`（f₁）或 `[[0.8,1],[1,0.8]]`（f₂），
与位置无关，因此任务书判据在整个区域上要么恒真要么恒假。

- f₁：整片区域都满足判据，Mask 是**一个**连通分量，但内部严格局部极大点为 0。
- f₂：整片区域都不满足判据，Mask 为空，内部极大点仍为 0。

在 N=33、65、129 上实测一致（`internal/ridge/counterexample_test.go`）。
这直接否证了“按该条件逐格判定的脊线一定连通成段”：判据可能给出一个不含任何
极值点的整片区域，也可能什么都不给；它并不是在找线。

## 5 正确的脊线判据与连通性

定义标量场

```
G(x,y) = ∇f · e₁ = fx·e₁ₓ + fy·e₁ᵧ
```

**命题 2.** 若 ∇f≠0，则 `G=0` 当且仅当 ∇f 与 e₁ 正交，即 ∇f ∥ e₂，
即梯度沿横截面方向，曲线沿脊方向走。再要求 `λ₁<0`，即横截面为凹，得到脊线。

于是脊线是**正则等值线** `{G=0}` 上 `λ₁<0` 的部分。只要 `∇G≠0`（非退化），
等值线就是 1 维流形；在方格网上用 marching squares 追踪，逐格连接关系为：

- 每个格边至多一个交点；每格贡献 0 或 2 条线段；
- 四角符号二二对半的模糊格用格心 G 的平均符号消歧。

**命题 3（连通性）.** 上述逐格连接得到的图，每个顶点度数 ≤2，因此每个连通分量
只能是**开链**（两个端点）或**闭环**（无端点）。不存在三叉或更高次的段。

证明：一个内部格边被相邻两个格子共享，两个格子各向其贡献至多一条线段，故该顶点
度数 ≤2。模糊格被拆成两条互不相接的线段，不产生分叉。∎

裁剪（只保留 `λ₁<0` 的线段）只会删边，不会提高剩余顶点的度数，结论不变。

两个画幅上由 `Ridge.Degree` 检查，全部顶点度数 ≤2，且每条开曲线恰有两个端点
（`TestCrestDegreeAtMostTwo`）。需要注意：**这一层的“连通成段”
是等值线追踪保证的，不是“逐格判定”保证的。** 任务书要求的“逐格判定”只能给出
区域（第 4 节反例），要得到线必须做等值线追踪。

## 6 段数写成极值点数的函数

### 6.1 对任务书判据（Mask）：离散 Morse 恒等式

把 Mask 看作 `Δf<0` 的负值集合，按 Δf 从低到高逐个加入格点（8 邻域）：

- 没有更低的 Mask 邻点：新开一段（birth）；
- 接到 1 个已有段：段数不变；
- 接到 k≥2 个已有段：合并，段数减 k−1。

按加入顺序对每个段维护并查集，最终

```
段数 = Births − Σ_merge (k−1)          (1)
```

这是恒等式，不是估计。`Births` 在无平台（相邻格点值不相等）的数据上恰好等于
“Δf 的严格局部极小点中 Δf<0 的个数”，`merge` 格是 Δf<0 的鞍型格点。

**命题 4.** Mask 的每个 8 连通分量都包含至少一个 Δf 的局部极小点（在 8 邻域、
存在邻点的意义下，允许取等：分量内最小格点的最小邻点值不小于它）。

证明：取分量内 Δf 最小的格点 v（有并列时任取一个）。若 v 有 Δf 严格更小的 8 邻点 u，
则 u 若在 Mask 内与“v 在分量内最小”矛盾；u 若不在 Mask 内，则 Δf(u)≥0>Δf(v)，
与“严格更小”矛盾。故 v 的任何 8 邻点都满足 Δf≥Δf(v)，v 是（弱）局部极小点。∎

因此内部段数 ≤ Δf 的内部局部极小点数。实测两画幅 101 个分量无一违反（用
`minimum_filter` 允许并值的判定，独立于 Go 实现）；上界为 478 / 498，很松。


### 6.2 对高度图本身：上升脊弧的计数

沿最陡上升方向，从每个格点追到局部极大点，得到上升脊网络。并查集从高到低扫描，
每次合并 k 个已有的下降分量产生一个鞍点，并贡献 k 条弧。若所有合并都是二元的
（通用情形，画幅上等高点对数为 0），则

```
鞍点数 S = P − 1
弧数 = P + S − 1 = 2P − 2                      (2)
```

其中 P 是高度图的严格局部极大点数。这是把“脊线段数”写成极值点数的**精确**函数。
实测 seed 7：P=60，S=59，弧=118=2P−2；seed 42：P=55，S=54，弧=108=2P−2。

### 6.3 两条关系的区别（必须讲清）

| 对象 | 段数公式 | 实测 |
|---|---|---|
| 任务书判据 Mask（区域） | 段数 = Births − MergeLoss，Births = Δf<0 局部极小点数 | 53 = 447 − 394；48 = 452 − 404 |
| 上升脊弧（高度图） | 弧数 = 2P − 2（二元合并） | 118；108 |

任务书把“段数”与“高度图局部极大点数”直接挂钩是不成立的：Mask 段数由 Δf 的
极小点数决定，不是由高度图的极大点数决定；反过来，高度图的极值点数决定的是
上升脊弧数（2P−2），不是 Mask 区域段数。

## 7 预测与实测的逐画幅比对

“按局部极大点数预判段数”这一说法本身没有唯一定义（Mask 的段并不一一对应极大点），
因此这里给出三种可核对的量，并在报告里逐行列出：

| 画幅 | 内部段数 / 上界(Δf内部极小) | 总段数 | 内部 | 触边 | 内部极大点 | 极大点在 Mask 内 | 多出 = 总段−在Mask内极大点 |
|---|---|---|---|---|---|---|---|
| seed 7, N=128 | 36 / 478 | 53 | 36 | 17 | 44 | 44 | 9 |
| seed 42, N=128 | 29 / 498 | 48 | 29 | 19 | 38 | 38 | 10 |

- **多出的段**（按极大点解释不了的段）：`Slack = 总段数 − 落在 Mask 内的内部极大点数`。
  两画幅分别为 9 和 10。细分：不含任何内部极大点的段 40 / 38 个；含极大点的段
  13 / 10 个，44 个极大点挤在 13 个段里，冗余 31（seed 42：38 个极大点挤在 10 个段里，
  冗余 28）。**逐项位置**见 `artifacts/seedXXX_n128.txt` 的“不含内部极大点的段”一节：
  id、格数、包围盒、质心、是否触边、最近极大点及距离，一行一个。
- **缺少的段**：内部极大点落在 Mask 外。两画幅均为 **0**，报告里显式写“无”。
  注意这不是定理保证的：引理 1 说明 `Δf<0` 与极大点无关，Mask 在原理上可以把
  极大点漏在外面（第 4 节的 f₂ 区域里就一个极大点也没有）。本数据上恰好没有漏，
  所以“缺少 0”是实测结果，不是推论。

**精确关系（第 6.1 节）**给出了 Mask 段数与真正对口的极值点（Δf 的极小点）之间的
恒等式，两画幅：

```
seed 7 : 53 = 447 − 394
seed 42: 48 = 452 − 404
```

## 10 结论

1. 任务书判别式可化简为 Δf<0（引理 1），它标记区域而非曲线；反例表明它不保证
   连通成段，也不含极值点（第 4 节）。
2. 正确的脊线是 `∇f·e₁=0` 且 `λ₁<0`；等值线追踪保证连通成开链/闭环（命题 3）。
3. 段数可以写成极值点数的函数，但要分清对象：Mask 段数由 Δf 的离散 Morse 关系
   精确给出（公式 1），高度图的脊弧数满足 2P−2（公式 2）。任务书“段数 = 高度图
   局部极大点数”的说法不成立。
