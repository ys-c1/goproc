# 最远点对的凸包对踵论证与旋转卡壳预判

本文论证两件事，并给出可复算的实现口径与验证方法：

1. **候选集收缩**：地形上任意两点的最远点对，必是凸包顶点上的一对对踵点对；因此只需考虑凸包顶点，无需遍历全部格子；
2. **不遍历全部点对的预判**：按凸包顶点的旋转卡壳（rotating calipers）可枚举出全部对踵点对并预判最远距离，枚举量是 \(O(h)\) 而非 \(O(n^2)\)。

记号：画幅为 \(S\times S\) 格，格子坐标取整数格 \((x,y)\)，\(0\le x,y\le S-1\)。候选点集 \(P\subset\mathbb Z^2\)，点距取欧氏距离，**距离按像素计**，两点坐标按整数格给出，距离取整到像素。平面坐标的 \(y\) 轴向下（图像行号），但这只改变手性，不改变距离与对踵关系。

## 1. 最远点对必在凸包上，且必为对踵点对

### 1.1 最远点对在凸包顶点上

设 \(d(A,B)=\max_{p,q\in P} d(p,q)\)。若 \(A\) 不在 \(P\) 的凸包 \(\mathrm{conv}(P)\) 的边界上，则 \(A\) 是凸组合 \(\sum_i \lambda_i V_i\)（\(\lambda_i\ge 0,\ \sum\lambda_i=1\)）内部的点。距离函数 \(p\mapsto d(p,B)\) 是凸函数，在凸集内部取极大值必在边界取得；进一步，对固定 \(B\)，\(d(\cdot,B)\) 在 \(\mathrm{conv}(P)\) 上的最大值必在某个**顶点**取得。若 \(A\) 在凸包边上但不在顶点，则它介于两顶点 \(V_1,V_2\) 之间，由凸性

$$
d(A,B) \le \max\{d(V_1,B),\,d(V_2,B)\}.
$$

故把 \(A,B\) 都替换为各自所在边的顶点不会减小距离。于是最远点对可取为两个凸包顶点。**候选集由全部格子（\(S^2\) 个）收缩为凸包顶点（\(h\) 个）**。实现见 `internal/caliper/caliper.go` 的 `Hull`，采用 Andrew 单调链，剔除共线点（`cross <= 0` 出栈），凸包顶点按逆时针（图像坐标下为顺时针可视）有序且无三点共线。

### 1.2 对踵点对的定义与「必为对踵」的论证

**定义（对踵点对）**：凸包有序顶点 \(V_0,\ldots,V_{h-1}\)（下标模 \(h\)）。若存在一条方向 \(\mathbf u\)，使 \(V_i\) 与 \(V_j\) 分别是凸包在 \(\mathbf u\) 与 \(-\mathbf u\) 方向上的支撑点，则称 \((V_i,V_j)\) 为一对对踵点对。等价地：过 \(V_i\)、\(V_j\) 的两条**平行支撑线**把整个凸包夹在中间。

**命题**：设 \((A,B)\) 是凸包顶点上的最远点对，则 \((A,B)\) 是对踵点对。

**证明**：记 \(L=d(A,B)\)，以 \(A\) 为心、半径 \(L\) 作圆 \(C_A\)。因 \((A,B)\) 最远，凸包 \(\mathrm{conv}(P)\subseteq C_A\)（任何凸包点离 \(A\) 不超过 \(L\)），且 \(B\in C_A\cap\mathrm{conv}(P)\)，即 \(B\) 落在圆上。在 \(B\) 处作圆的切线 \(\ell_B\)，其法向为 \(\overrightarrow{AB}\)。圆盘是凸集且包含凸包，故 \(\ell_B\) 是 \(\mathrm{conv}(P)\) 在方向 \(\overrightarrow{AB}\)（从 \(A\) 指向 \(B\)）上的支撑线。同理，以 \(B\) 为心、半径 \(L\) 的圆盘也包含凸包，在 \(A\) 处的切线 \(\ell_A\) 与 \(\ell_B\) 平行，是方向 \(-\overrightarrow{AB}\) 上的支撑线。于是过 \(A\)、\(B\) 的两条平行支撑线把凸包夹住，按定义 \((A,B)\) 是对踵点对。\(\square\)

> 注：这里只用到「凸包包含于两个半径 \(L\) 的圆盘」这一最远性推论，与凸包内部点无关；故论证对任意有限点集成立，不依赖地形高度分布。

> 直观：最远点对「撑满」了凸包直径，两侧的支撑线恰好垂直于连线。

### 1.3 结论与复杂度

- 候选从 \(S^2\) 个格子降到 \(h\) 个凸包顶点；
- 最远点对必在这些顶点的**对踵点对**之中，对踵点对的数量是 \(O(h)\)（每轮卡壳给出常数个）；
- 凸包构造 \(O(S^2\log S^2)\)（排序）或按栅格扫描 \(O(S^2)\)（本题用排序，画幅不大且可复算）；
- 枚举对踵点对 \(O(h)\)。

因此不需要遍历全部 \(S^2\cdot(S^2-1)/2=O(S^4)\) 个点对。

## 2. 旋转卡壳预判最远距离

### 2.1 卡壳的推进规则

对每条凸包边 \(E_i=(V_i,V_{i+1})\)，定义支撑函数（以有向面积表示，避免除零）

$$
A(i,j)=\operatorname{cross}(V_i,V_{i+1},V_j)
      =(V_{i+1}-V_i)\times(V_j-V_i).
$$

\(|A(i,j)|\) 等于以 \(E_i\) 为底、\(V_j\) 为顶点的三角形面积的两倍；在同一侧时 \(\arg\max_j A(i,j)\) 就是离直线 \(V_iV_{i+1}\) 最远的顶点——即边 \(E_i\) 的对踵顶点。

**单调性（卡壳可行的核心）**：当边 \(E_i\) 逆时针转到 \(E_{i+1}\) 时，最远顶点的下标 \(j(i)\) 在凸包上**只前进不后退**。因为凸包是凸的，支撑点随支撑方向连续单调移动。于是用一个游标 \(j\) 沿凸包单向推进即可：

```
j = 1
for i in 0..h-1:
    E = (V[i], V[i+1])
    当 A(i, j+1) > A(i, j):
        j = j + 1
    记录候选 (i, j) 与 (i+1, j)
    若 A(i, j+1) == A(i, j):        # 平行边：补记并排的两个对踵点
        记录候选 (i, j+1) 与 (i+1, j+1)
```

每轮边推进一次，游标 \(j\) 至多绕凸包一整圈，总推进次数 \(\le 2h\)，故**卡壳轮数 = 凸包顶点数 \(h\)**，游标总步数 \(O(h)\)，整体 \(O(h)\)。

### 2.2 卡壳覆盖全部对踵点对（预判的完备性）

**命题**：上述卡壳枚举出的点对集合，恰为凸包的全部对踵点对。

**证明草图**：
- (⊆) 当 \(j\) 使 \(A(i,\cdot)\) 取最大时，直线 \(V_iV_{i+1}\) 是方向 \(\mathbf e_i=V_{i+1}-V_i\) 的支撑线，过 \(V_j\) 的平行线是反方向支撑线；故 \((V_i,V_j)\) 与 \((V_{i+1},V_j)\) 均为对踵点对。平行情形同理。
- (⊇) 设 \((V_a,V_b)\) 是对踵点对，则存在方向 \(\mathbf u\) 使二者分别为 \(\pm\mathbf u\) 支撑点。随支撑方向在周角内转动，\(V_a\) 与 \(V_b\) 的支撑方向区间是凸包上两段圆弧；必有一个瞬间，\(V_a\) 的支撑方向与某条边 \(E_i\) 平行（\(V_a\in\{V_i,V_{i+1}\}\)），此时 \(j(i)\) 落在 \(V_b\)；卡壳在该轮记录该对。平行边情形的补记覆盖面积相等时的第二个对踵顶点。\(\square\)

> 注：卡壳输出的是**对踵点对集合**，不是「最远点对」的直接答案；必须再在对踵点对之间取距离最大值（2.3）。另外，只取每轮 `(i, j)` 的简化写法在随机与网格图形上都能取到直径（本实现也验证了这一点），但它不枚举完整的对踵点对集合，遇到并列/平行边时无法报告全部等距对；本实现按定义补记平行边情形，使枚举集与「逐边最大面积」定义**逐对相等**，`TestCalipersMatchesDefinition` 对此做全集对拍。

`internal/caliper/caliper_test.go` 的 `TestCalipersMatchesDefinition` 用穷举定义（对所有边取最大面积顶点）算出「理论对踵点对全集」，与卡壳枚举集逐对比较，随机与结构化图形均须相等。

### 2.3 从对踵点对到最远距离

最远距离为

$$
D_{\max}=\max_{(a,b)\in\mathcal A} d(V_a,V_b),
$$

其中 \(\mathcal A\) 为卡壳给出的对踵点对集合。由于 1.2 已证明最远点对属于 \(\mathcal A\)，此最大值即全局最远距离。比较在整数平方距离上进行（无浮点误差），最终距离取整：

$$
\boxed{\;\hat D=\left\lfloor\sqrt{D_{\max}^2}+\tfrac12\right\rfloor\;}
$$

坐标按整数格 \((x,y)\) 回报。

### 2.4 并列与平局

逐点比较用严格大于保留先到者，多边形面积相等（\(A(i,j{+}1)=A(i,j)\)，即两边平行）时补记第二个对踵点（见 2.1）。最远距离的平局按「平方距离相等」判定，并列时保留字典序最小的坐标对，保证结果可复算，且**不隐藏**另一个等距点对——并列数一并报告。

## 3. 验证：预判距离与暴力遍历逐画幅比对

「暴力遍历」指对**全部候选格**两两求距，不依赖凸包与卡壳。实现见 `internal/caliper.Brute`：对每个点 \(p\) 扫全部点的整数平方距离求最大，全体最大值即全局最大，所以结果与 \(O(n^2)\) 两两枚举完全一致，**不近似**（全程整数平方距离，无浮点）。两个画幅的候选规模约 1 万点，逐对比较约 4.8×10⁷ 与 6.4×10⁷ 次，Golang 实现约 50–170 ms（随机器波动），便于当基准真值。

比对口径：

- 每画幅分别跑「预判」与「暴力」，比较**平方距离**（精确）与**取整后的距离**（像素）；
- 两者任一不一致，报告该画幅的预判点与实测点**整数格坐标**；
- 距离全部按像素计，取整规则与 2.3 一致；
- `analysis/caliper_verify.py` 再用独立实现（numpy + 定义式对踵枚举）复算，三方对拍。

两个画幅的比对结果见 `artifacts/caliper/report.txt`（汇总表见 README 与 `artifacts/caliper/summary.csv`）。本次实测两画幅全部一致，故「不一致画幅」一栏为空。
