# 填洼水面高度与水面规模的判定（证明）

## 设定

- 高度场为八位灰度格 `G(c) ∈ [0,255]`，图边界格的水自由排出图外。
- 排水与溢流按**八邻域**（含对角）；水面像素的连通统计按**四邻域**。
- 填洼结果 `W` 是满足下列条件的最小曲面：
  1. `W(c) ≥ G(c)` 处处成立（只填不挖）；
  2. 每个非边界格 `c` 都有沿八邻域、`W` 不升的路径通到边界（水总能排走）。

  等价地（最小最大瓶颈形式）：

  ```
  W(c) = min_{P: c→边界} max_{p∈P} G(p)
  ```

  从边界出发的最小堆优先泛滥正是按此定义求 `W` 的**单遍**算法：堆弹出顺序即水位不降序，格 `c` 首次被弹出时的水位就是上式右端。每格只入堆出堆一次，不是迭代松弛。

## 命题1：水面高度只由洼地出口格高度的最小值决定

设 `R` 为填洼后某片水面（`{W > G}` 的四连通分量）。

**(a) `W` 在 `R` 上为常数。**
设 `a, b ∈ R` 四邻接（四邻接必为八邻接）。若 `W(a) < W(b)`，把 `b→a` 接上 `a` 的不升排水路径，得

```
W(b) ≤ max(G(b), W(a)) < W(b)
```

（严格小因为 `b` 是水格，`G(b) < W(b)`），矛盾。故四邻接水格水位相等；由 `R` 的四连通性，`W` 在 `R` 上为常数，记为 `S`（水面高度）。

**(b) `S` 等于出口格高度的最小值。**
令 `C ⊇ R` 为水位等于 `S` 的水格的八连通簇（溢流水体），**出口格**定义为与 `C` 八邻接的非水格（`W = G`）。记 `m` 为出口格高度的最小值。

- `S ≥ m`：任何从 `C` 到边界的八邻域路径，第一步走出 `C` 必落在某出口格 `n` 上，路径最高点 `≥ G(n) ≥ m`。由瓶颈定义 `C` 中每格 `W ≥ m`，即 `S ≥ m`。
- `S ≤ m`：考察优先泛滥中 `C` 里**第一个被弹出**的格 `a`。`a` 由某邻居 `n0` 出堆时扩展而来，`S = W(a) = max(G(a), W(n0))`，而 `G(a) < S`，故 `W(n0) = S`。`n0 ∉ C`（否则 `a` 不是 `C` 中第一个出堆的）；`n0` 也不是水格（水位为 `S` 的水格若与 `a` 八邻接则属于 `C`）。所以 `n0` 是出口格且 `G(n0) = W(n0) = S`，于是 `m ≤ S`。

由 `S ≥ m` 与 `S ≤ m` 得 **`S = m`**：水面高度只由出口格高度的最小值决定，与洼地内部形状无关。

## 命题2：由溢流高度可预判水面像素数与最大水深，无需迭代填洼

已知某洼地溢流高度 `S`（由命题1 取出口格高度最小值；优先泛滥单遍即得），设 `p` 为洼底（`R` 中任一格）。

**(a) 水面 `R` = `{c : G(c) < S}` 中含 `p` 的四连通分量。** 记该分量为 `D`。

- `D ⊆ R`：任取 `d ∈ D`。若存在从 `d` 到边界、全程 `G < S` 的八邻域路径，接上 `D` 内 `p` 到 `d` 的四连通路径，就得到从 `p` 到边界、全程 `G < S` 的路径，与 `W(p) = S` 矛盾。故 `d` 的每条出图路径最高点 `≥ S`，即 `W(d) ≥ S > G(d)`，`d` 是水格；同法知 `D` 内 `p` 到 `d` 路径上每格都是水格，故 `d` 与 `p` 四连通于水面内，`d ∈ R`。
- `R ⊆ D`：`R` 中每格 `G < W = S`，且 `R` 四连通含 `p`，故 `R ⊆ D`。

**(b) 水面像素数 = `|D|`**：对 `{G < S}` 做一次四连通洪泛即可数出，按四邻域连通计。

**(c) 最大水深 = `S − min_{c∈D} G(c)`（灰度差）**：水格 `c` 的水深为 `W(c) − G(c) = S − G(c)`，在分量最小灰度（洼底）处取最大。

**结论**：一次优先泛滥求各洼地的 `S`，再对 `{G < S}` 做一次四连通洪泛，即可预判每片水面的像素数与最大水深，全程无需迭代填洼。`cmd/goproc fill` 以迭代松弛填洼为对照，逐格比对预判掩膜与迭代掩膜（不一致格打印坐标），并逐湖核验 `S =` 出口格最小高度。
