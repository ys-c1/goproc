# 归一化饱和占比：上尾决定论、预判公式与两档实测比对

研究对象：`api.Generate` 的流水线 `fbm → hmap.Normalize → hmap.EncodePGM`。
归一化之后总有像素顶到 255，本文证明该占比由原分布上尾决定、给出只含尾部指数
与样本量的预判函数，并用两档分布参数做预判与实测的逐档比对。

复现（确定性，seed 固定）：

```
go run ./cmd/satstudy -out docs/saturation
```

## 0. 口径（定义）

- **饱和像素**：八位灰度量化后取值 **255** 的像素，即"顶档（255 档）及以上"
  的像素；8 位下 255 已是顶档，故口径即 `g = 255`。
- **量化规则**（`internal/hmap/hmap.go` `EncodePGM`）：`g = int(x*255 + 0.5)`，
  截断到 `[0,255]`。因此
  `g = 255 ⟺ x ≥ 1 − ε`，其中 **`ε = 0.5/255 = 1/510 ≈ 0.0019608`**。
- **归一化**（`hmap.Normalize`）：仿射拉伸 `x = (V − lo)/(hi − lo)`，
  `lo/hi` 为样本最小/最大值，`R = hi − lo` 为样本极差。
- 合并两式：**饱和 ⟺ 原始值 `V ≥ t`，`t = hi − ε·R`**。
- **饱和占比** `p = 饱和像素数 / N`，`N = size²`。
- 退化情形 `hi = lo`（常数场）全部置 0，无饱和，本文不讨论。

推论：最大值像素归一化后 `x = 1`，必饱和，故**饱和像素数恒 ≥ 1**，
占比恒 ≥ `1/N`——这就是"总有像素顶到 255"的直接原因；占比比 `1/N`
大多少，正是本文要预判的量。

## 1. 定理一：饱和占比由原分布的上尾决定

**命题** 设原始高度 `V₁…V_N` 的边缘分布为 `F`，生存函数 `S(v) = P(V > v)`。
则饱和事件只涉及上尾，且

```
E[p] = S(t) = S(hi − εR)
```

即期望饱和占比是原分布上尾在 `t` 处的取值，与分布的中下部（主体）无关。

**证明** 归一化 `x = (V − lo)/(hi − lo)` 在 `R > 0` 时是严格递增仿射变换，
保序、保分位。故事件链等价：

```
g_i = 255  ⟺  x_i ≥ 1 − ε  ⟺  V_i ≥ hi − εR = t
```

饱和计数 `K = #{i : V_i ≥ t}` 只由样本中不小于 `t` 的上尾部分决定；
取期望 `E[p] = E[K]/N = P(V ≥ t) = S(t)`（连续分布下 `P(V=t)=0`）。
`lo, hi` 本身也是样本的极端顺序统计量，其分布同样只依赖 `F` 的两端尾部。
故 `p` 是上尾形状的泛函：任意改动 `F` 在 `t` 以下的部分，`p` 不变。∎

## 2. 定理二：占比取决于尾部指数与样本量

本噪声有界（`|V| ≤ 1`，值噪声插值不越出格点值域，fbm 为加权平均亦不越界），
有界分布的上尾用**端点幂律**刻画（EVT 的 Weibull 吸引域）：

```
S(v) ≈ C·(v* − v)^β,  v → v*⁻,   β > 0 为尾部指数，C 为尾部系数，v* 为端点
```

**引理（极值条件）** 样本量 `N` 时，最大值 `hi` 的典型位置满足
`N·S(hi) ≈ 1`（最大值附近平均只剩一个样本），代入模型得
`v* − hi ≈ (C·N)^(−1/β)`。

**定理** 在上述模型下，

```
p_sat = S(t) = C·(v* − hi + εR)^β
             ≈ C·((CN)^(−1/β) + εR)^β
             = (1/N)·(1 + εR·(CN)^(1/β))^β      ……(★)
```

即 **`p_sat = f(β, C, R, N)`：给定尾部参数后，占比是样本量 `N` 的显式函数**，
与分布主体无关。

**证明** 由定理一 `p_sat = S(t)`，`t = hi − εR`，故
`v* − t = (v* − hi) + εR`；代入引理的 `v* − hi ≈ (CN)^(−1/β)`，
再提出 `(CN)^(−1/β)` 并用 `C·(CN)^(−1) = 1/N` 化简即得 (★)。∎

**讨论**

- `β = 1`（端点处密度非零，如均匀分布）：`p ≈ 1/N + εRC`，
  饱和像素数 `≈ 1 + εRCN`，**随 `N` 线性增长**——图越大，顶到 255 的越多。
- `β` 大（端点附近密度迅速归零）：`(CN)^(1/β)` 接近 1 的量级，
  `p → 1/N`，只剩最大值那一个像素饱和。
- 附注（无界帕累托尾情形）：若 `S(v) ~ C·v^(−α)` 且 `hi ≫ lo`，
  由 `hi ≈ (CN)^(1/α)` 同理得 `p ≈ (1/N)(1−ε)^(−α)`，
  同样只含尾部指数 `α` 与样本量 `N`。本文实验用有界端点模型 (★)。

## 3. 预判命题：不必先归一化再统计

**命题** 饱和占比可以在归一化之前预判。

**证明** 预判所需的全部量——`lo`、`hi`（两次遍历即得）、以及上尾拟合
`β̂, Ĉ`——都定义在**原始**样本上；归一化是严格递增仿射变换，不改变任何
序关系与分位数，因此用原始数据拟合的 `S` 与归一化后再统计是同一事件
（定理一的等价事件链）的两种算法。把 `t = hi − εR` 代入拟合模型即得
**预判式**

```
p̂ = Ĉ·(εR)^β̂          （经验式，用实测 hi, lo）
p̂ = (1/N)(1 + εR(ĈN)^(1/β̂))^β̂   （先验式 (★)，含端点间隙修正）
```

全程不执行归一化与量化。∎

## 4. 实验设置

两档分布参数（其余参数相同：`size=512`，`N = 262144`，`seed=7`，
`freq=0.02`，`lacunarity=2.0`）：

| 档位 | octaves | gain | 预期尾部 |
|---|---|---|---|
| A（`A_oct1_g05`） | 1 | 0.5 | 单层值噪声，有界端点尾（Weibull 域） |
| B（`B_oct8_g08`） | 8 | 0.8 | 多层近等权叠加，CLT 近高斯（Gumbel 域） |

**尾部指数估计（双对数拟合）**：把样本排序，取经验生存函数
`S(v_i) = (N − i − ½)/N`，对点 `(ln(hi − v_i), ln S(v_i))` 做最小二乘，
斜率即 `β̂`，截距给 `Ĉ`。每档各用两个**拟合区间**（经验分位口径）：

| 区间 | 分位范围 | 档位 A 实际值域 | 档位 B 实际值域 | 拟合点数 |
|---|---|---|---|---|
| W（宽） | [0.90, 0.999] | [0.6192, 0.9817] | [0.2171, 0.4722] | 25952 |
| D（深） | [0.999, 0.99995] | [0.9817, 0.9991] | [0.4722, 0.5504] | 249 |

阈值亏量 `εR`：档位 A 为 `0.00392`（`t = 0.99608`，经验分位 0.9998）；
档位 B 为 `0.00259`（`t = 0.63686`，经验分位 > 0.99995）。

**实测**：用生产代码同一规则（`hmap.Normalize` + `int(x*255+0.5)`）
归一化量化后数 `g = 255` 的像素。

**判定**：相对偏差 `|p̂ − p|/p > 10%`（一成）的档位须说明尾部估计问题。

| 档位 | 区间 | β̂ | Ĉ | R² | p̂（经验式） | p̂（先验式★） | p 实测 | 饱和像素 | 相对偏差 |
|---|---|---|---|---|---|---|---|---|---|
| A | W | 1.601 | 0.441 | 0.9936 | 6.18e-05 | 8.01e-05 | 1.945e-04 | 51 | **68.2%** ✗ |
| A | D | 0.866 | 0.0231 | 0.9343 | 1.90e-04 | 1.92e-04 | 1.945e-04 | 51 | **2.2%** ✓ |
| B | W | 4.973 | 7.50 | 0.9996 | 1.0e-12 | 4.81e-06 | 7.63e-06 | 2 | **≈100%** ✗ |
| B | D | 4.737 | 4.66 | 0.9979 | 2.6e-12 | 4.80e-06 | 7.63e-06 | 2 | **≈100%** ✗ |

注意一个反直觉点：档位 B 的 R²（0.998–0.9996）比档位 A 的 D 区间（0.934）
**更高**，预判却彻底失败——受限区间上的拟合优度不能背书区间外的外推。

## 6. 超一成档位的尾部估计问题

### 6.1 档位 A / 区间 W（偏差 68.2%）：区间太浅，指数被主体污染

- 阈值亏量 `εR = 0.0039`，而 W 区间亏量跨度 `0.018 ~ 0.38`，
  外推距离 1~2 个数量级。
- 双对数图（`tierA_oct1_g05_tailfit.png`）整体明显弯曲：W 拟合的
  `β = 1.60` 是"主体 + 尾"的平均斜率，不是渐近尾部指数。
- 区间加深后 `β` 从 1.60 漂到 0.87；用阈值两侧两点估算的真实局部斜率
  `ΔlnS/Δln d ≈ ln(1e-3/1.945e-4) / ln(0.0183/0.0039) ≈ 1.06`，
  与理论一致——任何光滑分布在最大值附近都有 `S(v) ≈ f(hi)·(hi−v)`，
  **局部指数恒趋于 1**。深区间 D 正是落在这个局部线性区，于是命中
  （2.2%，且在 51 个像素的 Poisson 涨落 ±14% 之内）。
- 教训：端点幂律的 `β` 是渐近量，**拟合区间必须压在阈值亏量尺度附近**；
  用远离阈值的宽区间拟合再外推，指数被分布主体污染，必然偏差超一成。

### 6.2 档位 B / 两个区间（偏差 ≈100%）：模型误设，Gumbel 域无幂律指数

- 8 层 gain=0.8 的 fbm 是近等权多分量之和，由中心极限定理接近高斯
  （灰度直方图 `tierB_oct8_g08_gray_hist.png` 呈钟形），属 **Gumbel
  吸引域**：尾部是指数型衰减，**根本不存在有限的亏量幂律指数**。
- 证据是指数不随区间加深而稳定：W 给 4.97、D 给 4.74，而阈值尺度的
  真实局部斜率仅 `≈ ln(5e-5/7.63e-6)/ln(0.089/0.0026) ≈ 0.53`——
  局部"指数"随尺度从 ~5 一路缩到 ~0.5，任何单一 `β` 的双对数外推
  都会崩。拟合线再直（R²=0.9996）也只是局部切线。
- 外推跨度同样致命：阈值亏量 `0.0026`，D 区间亏量 `0.089 ~ 0.167`，
  差 1.5 个数量级以上。
- 计数涨落：实测只有 **2 个**饱和像素，Poisson 相对涨落约 ±71%，
  即使模型正确，"一成"判据在统计上也几乎不可能满足。要压到 10%
  需要 `N·p ≳ 100`，由 (★) 可反解所需 `N`（约需把 `N` 放大两个量级）。
- 补救方向：Gumbel 域应改用指数尾模型（`ln S` 对 `v` 线性的**单对数**
  拟合），或在阈值附近直接用经验计数/局部密度 `f(hi)` 估计
  `p ≈ f(hi)·εR`；亏量幂律双对数外推对此类分布不适用。
- 附记：先验式 (★) 在档位 B 给出 4.8e-6，看似接近实测 7.6e-6
  （偏差 37%，仍超一成），但其中的端点间隙项 `(CN)^(−1/β)` 同样
  建立在错误的 `β` 上，量级吻合属巧合，不足为凭。

### 6.3 两档共有的注意事项

- **空间相关性**：值噪声在基频 0.02 下一个格子约 50 像素，极端值成片
  出现，有效样本量小于 `N`，实测占比的涨落比 iid Poisson 更大；
  定理二的 `N` 严格说是独立副本数，相关场下应理解为有效样本量。
- **实测口径**：`p_meas = S(t)` 是同一批样本的自洽测量（`t` 由该样本的
  `hi, lo` 决定），种子不变则结果完全确定，可复现。

## 8. 结论

1. 饱和占比 `p = S(hi − εR)`（`ε = 1/510`），**只由原分布上尾决定**；
   端点幂律模型下 `p = (1/N)(1 + εR(CN)^{1/β})^β`，**只依赖尾部指数、
   尾部系数、极差与样本量**。
2. 该函数全部量在原始数据上可得，**归一化前即可预判**，无需先归一化
   再统计。
3. 实证：尾部属 Weibull 域（档位 A）时，拟合区间贴近阈值亏量尺度
   （D 区间）预判偏差 2.2%；区间太浅（W）偏差 68%。尾部属 Gumbel 域
   （档位 B）时亏量幂律模型误设，任何区间都失败，应换指数尾模型。
