# 种子独立性检验：换种子是否等于换一批独立格点值

## 1. 可检验命题

记种子 `s` 派生出的置换表为 `P_s`（`internal/noise/noise.go` 中 `New(s)` 的产物）。
整数格点 `(ix, iy)` 上的**原始格点值**定义为

```
G_s(ix,iy) = perm[(perm[ix mod 256] + iy) mod 512] / 127.5 − 1
```

插值噪声 `Value` 是相邻四个格点值经 fade 加权的凸组合，因此格点值是整个派生链的最底层随机量。

**命题（H0，零协方差）**：把种子 S 视为随机变量，对任意固定位置 p 与任意固定种子间隔 Δ，

```
Cov( G_S(p), G_{S+Δ}(p) ) = 0
```

可操作的检验版本：抽取 n 个独立的成对样本 `(S_k, S_k+Δ)`，每对在（同样独立抽取的）位置 p_k 取值，
计算样本协方差

```
Ĉ = (1/n) Σ_k X_k Y_k − X̄·Ȳ,   X_k = G_{S_k}(p_k), Y_k = G_{S_k+Δ}(p_k)
```

H0 下 `E[Ĉ]=0`；若派生有偏，`E[Ĉ]≠0`，且随 n 增大 Ĉ 会稳定偏离零点并**超出波动范围**。

## 2. 当前派生方式下的证明（在标准随机置换模型内）

派生链为：`seed →(splitmix64 迭代)→ 255 个伪随机数 →(Fisher–Yates)→ 均匀随机置换 P_s → 格点值 G_s`。

采用该结构对应的标准理想化模型：**把 splitmix64 视为随机函数（PRF 模型）**，
即每次迭代输出视为独立均匀的 64 位比特串。这是对任何「哈希 → 洗牌」式种子派生唯一可做的
模型化论证——确定性函数本身不存在数学上的「独立」，独立性只能按随机函数假设论证、再用经验检验复核。

1. `state_k = splitmix64(state_{k−1})` 在 PRF 模型下是独立均匀随机变量；
2. Fisher–Yates 以 `j = state_k mod (i+1)` 选交换目标，其输出 P_S 在 256! 个置换上**均匀分布**，
   且两个不同输入种子 S、S+Δ 喂养出两条独立随机链，故 `P_S` 与 `P_{S+Δ}` 相互独立；
3. 对固定位置 p，`G_s(p)` 只是 `P_s` 的确定函数。独立随机变量的确定函数仍独立，
   故 `G_S(p)` 与 `G_{S+Δ}(p)` 独立；
4. 格点值有界（见下，E[G]=0），协方差存在，独立 ⇒ `Cov = E[XY] − E[X]E[Y] = 0`。 ∎

该证明的强度完全取决于 splitmix64 是否近似随机函数。**第 4 节的经验检验就是对这一前提的复核**，
且专门覆盖最容易暴露弱点的「输入仅差 1」的相邻种子档。

### 格点值的精确理论矩

置换表元素 h 在 `{0,…,255}` 上均匀，`G = h/127.5 − 1`：

```
E[G]   = (1/256) Σ_h (h/127.5 − 1) = 0
Var(G) = (1/256) Σ_h G² = 255·257/(3·255²) = 65535/195075 ≈ 0.335948
E[G⁴]  ≈ 0.203145
```

## 3. 样本量不足时协方差估计的波动范围

H0 下 X、Y 独立且均值为零，`E[X²Y²] = E[X²]E[Y²] = Var(G)²`，故

```
Var(Ĉ) = Var(G)² / n ≈ 0.11286 / n
```

给出三档范围（n=4096，σ = Var(G)/√n ≈ 0.00525）：

| 范围 | 公式 | 门限值 | 性质 |
|---|---|---|---|
| 95% CLT | ±1.96σ | **±0.01029** | 大样本实用，双侧 95% |
| 3σ 判据 | ±3σ | **±0.01575** | 几乎必中（99.73%），程序的自动判据 |
| Chebyshev 95% | ±√20 σ | **±0.02348** | 不依赖分布形状的有限样本严格界 |

一般地，样本量 n 下门限按 1/√n 缩放；n 减半则门限放大 √2 倍。
对插值噪声 Value（方差无闭式值），程序用样本方差 `Vx·Vy/n` 代入同一公式。

## 4. 实测：三档种子间隔并排对照（每档 n=4096 独立成对样本）

种子段互不相交：gap=1 取自 1e6 段、gap=2^16 取自 2e6 段、gap=2^32 取自 3e6 段；
位置由与种子无关的 LCG 在 256×256 格点上均匀抽取，保证 `(S_k, p_k)` 独立同分布。

### 4.1 底层格点值 Lattice —— 命题的直接对象

| 间隔 | 实测 Ĉ | 95% CLT 范围 | 3σ 判据 | Chebyshev 95% | 判定 |
|---|---:|---:|---:|---:|---|
| Δ=1（相邻种子） | **+0.00077** | ±0.01029 | ±0.01575 | ±0.02348 | 在范围内 |
| Δ=65536 | **−0.00377** | ±0.01029 | ±0.01575 | ±0.02348 | 在范围内 |
| Δ=2^32 | **−0.00357** | ±0.01029 | ±0.01575 | ±0.02348 | 在范围内 |

三档 |Ĉ| 最大 0.00377，不足 95% 门限的 37%。样本方差（0.326–0.341）与理论 Var(G)=0.3359 吻合。

### 4.2 插值噪声场 Value（4 层 fbm，图像实际使用的量）

### 4.3 阳性对照（检验自身的检出能力）

令 X=Y（同一种子与自身配对），理论偏倚为 Var(G)≈0.3359，实测 Ĉ=+0.33461，
是 3σ 门限的 21 倍，正确报「超界」。说明本检验若真遇到派生有偏不会漏报。

## 5. 那两幅图为什么还是像？—— 图级相关的真实来源

按完整管线生成两幅 128×128 高度图（seed 42 / 43，参数同默认），图级 Pearson 相关：

| 间隔 | 图级 r | 置换表格点重合率 |
|---|---:|---:|
| Δ=1 | +0.4928 | 0.0042（独立期望 1/256=0.0039） |
| Δ=65536 | +0.3032 | 0.0039 |
| Δ=2^32 | +0.1319 | 0.0038 |

置换表层面三档都恰好等于随机重合期望，**派生没有共享任何格点数据**。图级相关来自两个结构性原因：

1. **空间自相关吞噬了有效样本量**。基础频率 0.02 意味着一个噪声格点跨度为 50 像素，
   实测水平 lag-1 自相关 ρ=0.995，16384 个像素的有效样本量仅 **ESS≈40**。
   独立样本下 r 的 1σ≈0.159，于是 r=0.49 只是约 3.1σ 的单次抽样波动；
2. **值噪声的平滑核决定了共同的「质感」**。频率分解实验：同一对种子，
   freq=0.005 时 r≈0.80、freq=0.02 时 r≈0.52、freq≥0.08 时 r≈0。
   低频下每个输出是大量相邻格点的加权平均，平均掉了格点层面的独立性差异，
   留下的是插值核形状本身——它与种子无关，所有图天然都长着同一种「云雾」。

即「像」的是**频谱与相关结构（由 Frequency/Octaves/插值核决定）**，不是随机内容；
换种子换掉的斑块位置在两张留档图（`artifacts/maps/seed_0042.png`、`seed_0043.png`）上明显不同。
若要让图与图之间在观感上也更独立，应提高 `Frequency` 或减小 `Octaves` 中低频层的权重，
而不是改种子派生。
