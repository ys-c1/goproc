# 地形阴影：包络判据与一次扫掠的证明

## 设定

高度场 `H` 定义在 `size × size` 网格上。光源为方向光（无穷远），用两个角描述：

- 方位角 `az`：水平面内**指向光源**的单位向量 `u = (cos az, sin az)`（图像坐标，y 向下）；
- 高度角 `α`：光线相对水平面的仰角。

从格 `p` 向光源看，水平距离 `t` 处光线的高度为 `h(p) + t·tanα`。

## 引理（遮挡判据）

格 `p` 处于阴影，当且仅当存在 `t > 0` 使射线 `γ_p(t) = p + t·u` 上的地形高于光线：

```
∃ t > 0 :  H(γ_p(t)) ≥ h(p) + t·tanα
```

## 命题 1：阴影只由光线方向上的高度包络决定

**定义（包络）** 沿光线方向的累积最大高度（扣除光线爬升）：

```
E(p) = sup_{t>0} [ H(γ_p(t)) − t·tanα ]
```

**命题** `p` 处于阴影 ⟺ `h(p) ≤ E(p)`。

**证明** 由引理：

```
p 阴影 ⟺ ∃ t>0 : H(γ_p(t)) − t·tanα ≥ h(p)
       ⟺ sup_{t>0} [ H(γ_p(t)) − t·tanα ] ≥ h(p)
       ⟺ E(p) ≥ h(p)
```

右端只含射线 `γ_p` 上的高度值与常量（`u`、`α`），与射线路径之外的地形无关。
即：阴影判定完全由"该格到光源方向上的高度包络"决定。∎

## 命题 2：包络可一次扫过求出，无需逐格步进

取步长 `Δ = 1` 格，记 `r = γ_p(Δ) = p + u` 为射线上前进一格的（一般非格点的）点。
把命题 1 中的 sup 在 `t = Δ` 处拆开：

```
E(p) = max( H(r) − Δ·tanα,  sup_{t>Δ} [ H(γ_p(t)) − t·tanα ] )
```

对第二项换元 `s = t − Δ`，注意 `γ_p(t) = γ_r(t − Δ) = γ_r(s)`：

```
sup_{t>Δ} [ H(γ_p(t)) − t·tanα ] = sup_{s>0} [ H(γ_r(s)) − s·tanα ] − Δ·tanα
                                  = E(r) − Δ·tanα
```

于是得到递推：

```
E(p) = max( H(r), E(r) ) − Δ·tanα        ……(∗)
```

**终止性**：`r` 的投影严格大于 `p` 的投影（恰好多 `Δ`），递推沿光线方向严格前进，
链无环，且有限步内必出界；出界格 `E = −∞`（必受光）。

**算法**：把高度场重采样到**光线对齐网格** `(s', t')`（`t'` 沿光线方向、
`s'` 垂直光线，间距均为一格）。在该网格上 `r` 恰好是格点，递推 `(∗)` 
化为逐行的一维累积最大：

```
E'(s', t') = max( H'(s', t'+1), E'(s', t'+1) ) − tanα
```

沿 `t'` 降序（光线反方向）每行扫一遍即得全部 `E'`，再插值回原格点，
按命题 1 逐格判定。全图 `O(N)`，每格 `O(1)`，无需逐格步进
（步进法每格 `O(L)`，`L` 为图内光线长度，全图 `O(N·L)`）。∎

## 离散化说明（两法为何会有零星差异）

命题 2 的递推要求"射线上前进一格的点 `r`"处的 `H` 与 `E` 值，而 `r` 一般不是
原网格格点。取值方式决定误差形态，实现中对比过三种：

- **位置取整链（不可取）**：`q = round(p+u)` 再沿 q 的链递推，取整误差逐步累积，
  链相对真实射线**线性漂移**（如方位 300° 时链退化成 45° 对角线），实测误差率 4~5%；
- **原网格上边递推边插值（不可取）**：每格在精确点 `r` 处对 `E` 双线性插值，
  包络场在遮挡物锥顶处呈 ∧ 形折点，插值削顶**沿链逐步累积**，
  低高度角长阴影下实测误差率可达 10%；
- **光线对齐网格重采样（本实现）**：先把 `H` 重采样到光线对齐网格
  （一次有界插值误差），递推在该网格上是**精确的一维累积最大**，
  不引入新误差；算完插值回原网格（再一次有界插值误差）。
  步进法在同一双线性高度场上沿精确射线采样，两法共享同一射线定义。

残余不一致只来自两次插值对阴影边界的亚格级移动，集中在边界带上。
另外，光线出界的网格点包络记为"无约束"而非高度值，回插时只在有约束的
角点上按权重归一化，否则地图边缘一格宽的遮挡条会被负无穷稀释掉。
实测误差率 0.1~0.9%（随高度角降低、阴影变长略升），具体数值见运行报告。
