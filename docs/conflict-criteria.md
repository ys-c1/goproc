# 坡向着色与阴影的冲突判据

## 记号

高度图 `h(x,y)` 归一化到 `[0,1]`，`x,y` 以格点计，故一阶差分的量纲是"高度/格"。

- 坡向单位法向：`N = (-p, -q, 1)/√(1+p²+q²)`，`p=∂h/∂x`，`q=∂h/∂y`
- 光照单位向量：`L = cos(e)·w + sin(e)·ẑ`，`w=(cos az, sin az)`，`e` 为仰角
- 沿光方位方向导数：`u = ∇h·w = p·cos az + q·sin az`

## 判据 A：坡向朝光

坡向着色层 `shade = ambient + (1-ambient)·max(0, N·L)`。判据 A 取"N·L ≥ 0"：

```
N·L = (sin e - u·cos e) / √(1+p²+q²)
```

分母恒正，于是

```
N·L ≥ 0  ⟺  sin e - u·cos e ≥ 0  ⟺  u ≤ tan e          …… (1)
```

即"坡向朝光"等价于方向导数不超过 `tan(e)`。`render_test.go` 的
`TestLitEquivalentToSlopeInequality` 在随机起伏面上逐格验证了这条恒等式。

## 判据 B：深度差在阈值内

沿光线步进，遮挡体高出光线的量

```
gap(x,y) = max_{s>0} ( h(x+s·cos az, y+s·sin az) − h(x,y) − s·tan e )₊
```

判据 B 取 `0 < gap ≤ τ`。`gap = 0` 表示光线一路走空（完全未被遮挡），
必须排除，否则整片平原都会满足 `gap ≤ τ`。

## 合取化简

记 `φ(s) = h(x+s·w) − h(x) − s·tan e`。则 `φ(0)=0`，`φ'(0) = u − tan e`，
且 `gap = max_{s>0} φ(s)`。两条判据是：

```
A:  φ'(0) ≤ 0
B:  0 < max_{s>0} φ(s) ≤ τ
```

因此合取**不能**化简成"单个不含 A 的不等式"：A 约束的是 `φ` 在 `s=0` 处的导数，
B 约束的是 `φ` 在 `s>0` 上的上确界，两者自变量不重叠。

它确实能写成一条"光线包络"式的不等式组：

```
φ'(0) ≤ 0   且   0 < max_{s>0} φ(s) ≤ τ
       ⟺   max_{s>0} φ(s) ≤ τ   且   φ 的最大值在 s>0 取得
```

只有当 `τ → 0` 时差集才消失（数值见下），但 τ=0 时判据退化为空集，故在任意
`τ>0` 上 A 都是独立约束，**不可消去**。数值残差 `|B \ A| / |B|`：

| τ     | \|B\| | \|A∧B\| | \|B\A\| | 残余 |
|-------|------|---------|--------|------|
| 0.002 | 173  | 172     | 1      | 0.6% |
| 0.005 | 370  | 366     | 4      | 1.1% |
| 0.010 | 685  | 656     | 29     | 4.2% |
| 0.020 | 1055 | 887     | 168    | 15.9%|
| 0.040 | 1314 | 982     | 332    | 25.3%|

## 两种"坡向与光照夹角"的读法

用户原话是"坡向与光照夹角落在一侧"。这句话有两种读法，含义相反：

| 读法 | 不等式 | az=45 命中 | az=135 命中 |
|------|--------|-----------|------------|
| A1 受光一侧（含擦过） | `N·L ≥ 0`，即 `u ≤ tan e` | 857 | 887 |
| A2 严格迎光 | `u ≤ 0` | 0 | 9 |
| A3 背光一侧 | `u ≥ 0` | 953 | 1046 |

A1 几乎恒真（全图 97.2% 满足），因为仰角 2° 时 `tan e = 0.0349` 大于绝大多数
方向导数；A2 在本图上近乎空集。两种读法给出的"冲突格"数量差两个数量级，
所以结论对读法极度敏感，必须先钉死定义。本文与代码采用 A1。

## 该地图上判据的实际行为

参数：size=128，seed=7，octaves=4，az=135°，elev=2°，τ=0.02。

- 最大方向导数 `max|u| = 0.0584`，对应最大坡度 **3.34°**；`tan(2°)=0.0349`。
- 判据 A 在地图上成立 **97.2%**（15927/16384）：低太阳下几乎整幅图都朝光，
  A 近乎空泛。
- 判据 B 成立 1055 格，合取 **887 格**。
- 冲突格在合成亮度分布中位于 **p3–p68**，中位数 p6.9；全图"亮"（高于 p50）
  的格子里，冲突格占 **1/887**。这些格不是"既亮又暗"，而是接近最暗的一档。
- 若把"亮"定义为 `N·L ≥ 0.2`（夹角小于 78°），整幅地图**一格都没有**。
- 冲突格的最大 `N·L = 0.044`，即与光照夹角 87.5°，着色值 0.256（全图着色
  区间 0.250–0.320，标准差仅 0.013）。它们不是"既亮又暗"，而是**最暗的一档**。

## 人工标注可达性的硬上界

即使三位标注者彼此完全一致，IoU 也不可能超过 `|C∩V| / |C∪V|`，`V` 是
能被人眼分辨的像素集（局部对比超过给定灰度级）：

| 可见性阈值 | `|V|`（全图） | `|C∩V|` | IoU 上界 |
|-----------|--------------|---------|---------|
| > 2 灰度级 | 1122 | 450 | **0.507** |
| > 5 灰度级 | 208 | 71  | **0.080** |

即"三人重叠率都过八成"在任何标注方式下都无法达成，因为判据圈出的格子在画面上
几乎与背景同色。这不是标注者水平问题，是判据与可辨识性不匹配。

## 两个光照角之间的一致性

az=45° 得 857 格，az=135° 得 887 格，交集仅 61 格，**Jaccard = 0.036**。
"冲突"几乎完全随光照方向改变，不具备跨视角的稳定性，更像阴影边缘的偶然产物。

## 阴影层为何没有遮挡

仰角 2° 时 `tan e = 0.0349`，地形最大坡度 3.34° < 2°，理论上一条边界射线。
实测覆盖 311 格（1.9%），且全部落在边界附近——高度图归一化到 `[0,1]` 而水平
单位是格，导致地形的"真实"坡度被压到 3° 以下。仓库里没有渲染器，本分析新增的
`internal/render` 就是这一定义；若下游另有垂直比例约定，需在 `Params` 里显式给出。
