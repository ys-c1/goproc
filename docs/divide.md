# 分水线（山与山的分界）直接描线法

目标：在高度图上画出山与山之间的分界线，避开“逐格洪泛”的高成本做法，
直接由每格的局部流向判定分界格边，再把格边描成线。

## 1. 记号与流向

高度图是 `n×n` 的格集，格 `p` 高度 `h(p)`。每格在八邻域（D8）中选**归一化最陡下降**
邻居作为唯一去向 `f(p)`：

```
f(p) = argmax_q  (h(p) - h(q)) / d(p,q)
```

其中正交邻居 `d=1`，斜向邻居 `d=√2`；只接受严格为正的下降，没有更低邻居时 `f(p)=∅`。
多个邻居下降量并列时按固定方向优先级 `N,NE,E,SE,S,SW,W,NW` 取第一个，结果完全确定。

沿 `f` 不断前进，高度严格下降，必然在某个 `f(p)=∅` 的格终止，这个终点称为**汇（sink）**，
记作 `sink(p)`。一座山的汇水盆地就是 `sink(·)` 相同的格的集合。

## 2. 证明一：分界线必由“两侧流向相反”的格边组成

考虑任意一条内部格边 `e`，它分隔两个相邻格 `a`、`b`。

**引理（流向决定汇）**：每格的汇 `sink(p)` 由其流向唯一确定——沿 `f` 走到的终点即汇，
与起点之外的格无关。

**命题**：`e` 是两座山的分界，当且仅当 `a`、`b` 两侧的流在该边处方向相反（各自背离 `e`），
等价于 `sink(a) ≠ sink(b)`。

- 充分性：若两侧流向相反、各自背离 `e`，则从 `a` 出发的流线和从 `b` 出发的流线永不在
  `e` 处汇合（流线只沿下降方向，无法回头跨过 `e`），它们终止于不同汇，故 `e` 分隔两个盆地，
  是分界。
- 必要性：若 `e` 是分界（`sink(a) ≠ sink(b)`），则 `a`、`b` 不可能都把水送过 `e` 流向同一侧，
  否则二者沿同一通道汇入同一汇；在“每格单一下降去向”的确定性流场下，分界处的两个格必然
  一个把水排向 `e` 的这一侧、另一个排向另一侧，即流向相反、各自背离 `e`。

因此**分界格边集合**可直接写成坐标集合（`n` 为边长）：

```
E_H = { (x,y) | 1≤y<n, 0≤x<n, sink(x,y-1) ≠ sink(x,y) }   （水平格边）
E_V = { (x,y) | 1≤x<n, 0≤y<n, sink(x-1,y) ≠ sink(x,y) }   （竖直格边）
```

其中最严格、可只凭流向判定的“法向分量相反”子集为：

```
E_H^⊥ = { (x,y) | f(x,y-1) 含北分量 且 f(x,y) 含南分量 }
E_V^⊥ = { (x,y) | f(x-1,y) 含西分量 且 f(x,y) 含东分量 }
```

`E_H^⊥ ⊆ E_H`、`E_V^⊥ ⊆ E_V`：严格相背流一定汇入不同汇，但完整分界还包含斜向分流等情形，
故完整集合以“汇不同”为准。程序同时输出两者（`*_divide.txt` 与 `*_opposite.txt`）。

## 3. 证明二：凭该集合可直接描线，无需洪泛标号

传统洪泛从每个汇向全图扩散盆地标号，再找标号相异的相邻格——每个格都要被入队处理。
本方法不需要这一步：

1. 每格的汇由它**自己的流向链**决定。用记忆化指针追踪：顺 `f` 走到汇，沿途回填同一汇号，
   每条流向链只走一次，总时间 `O(n²)`；没有“从汇向全图扩散”的洪泛过程。
2. 得到每格汇号后，对每条内部格边做一次 `O(1)` 的相邻汇号比较，相异即收入 `E_H/E_V`。
3. 描线只在已选出的格边上做图遍历：格边是边、网格顶点是节点，共享顶点即相连，
   求连通分量即得一条条分界线（`Trace`），同样不触及普通地形格、不做盆地标号。

故总复杂度 `O(n²)` 时间、`O(n²)` 空间，且全程无逐格洪泛。

## 4. 平地格子的处理

严格下降选向在等高水平台地（plateau）上会得到一组 `f(p)=∅` 的格，需要区分两种情况：

- **斜台地（可排水）**：台地的同高度连通体边缘存在严格更低格。以这些“排水口”为起点，
  在同高度连通体内做有界 BFS，把台地内部格统一指向排水口方向。BFS 被严格限制在同高度体内，
  不跨高度、不改写普通坡格。
- **闭洼地（真汇）**：台地四周都不低于自身、没有任何排水口，连通体保持 `f(p)=∅`，
  作为汇终止流向，符合“水往低处流、闭洼不出水”。

同台地有多个排水口时按扫描顺序取首个方向，保证确定性。等高台地不满足脊线的“严格高于”
判据，因此不会在对照脊线里产生成片伪脊。

## 5. 与人工/独立脊线的逐像素比对

独立脊线检测（`Crest`，与流向完全解耦）：格在四条过格轴线（水平、竖直、两条对角）任一上
为严格局部极大即为脊像素。该判据在两画幅上分别给出 1107、1000 个脊像素。

比对（`tools/crest_vs_divide.py`）做双向 Chamfer 距离分析，容差 2 格：

- 第一组 脊线→分水线：距最近分界格边超过 2 格的脊像素，聚成 8 邻接段并给坐标；
- 第二组 分水线→脊线：中点距最近脊像素超过 2 格的格边，同样聚段给坐标。

两类对象的固有差异：分水网沿**盆地之间**的格边走（受离散 D8 流向约束，呈轴对齐/45° 阶梯），
独立脊线沿**局部最高像素**走（连续脊中心线）。二者在主脊上重合度高，在缓坡、鞍部和图幅边缘
出现 1–数格偏差，报告把所有超阈值段落坐标逐一列出。

## 6. 复现

```bash
make test                 # Go 单元测试 + vet
bash artifacts/build/measure.sh
```

`measure.sh` 对两个画幅（seed 19 / seed 8）各产出：
`*_divide.txt`（完整分水线 H/V 坐标）、`*_opposite.txt`（严格反向边子集）、
`*_crest.txt`（独立脊线像素）、`*_gray.png`、`*_overlay.png`（叠加图，蓝=H、红=V）、
`*_compare.txt`（两组偏差与超 2 格段落坐标）。
