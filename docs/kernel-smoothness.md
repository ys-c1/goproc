# 插值核光滑度证明与格点跳变实验

## 记号与一维单元形式

值噪声在网格单元 `[i, i+1]` 内把相邻格点值 `g_i, g_{i+1}` 用淡入淡出核 `w:[0,1]→[0,1]` 插值：

```
f(x) = g_i + (g_{i+1} − g_i)·w(t),  t = x − i ∈ [0,1],  记 Δg_i = g_{i+1} − g_i
```

链式法则给出单元内导数：

```
f′(x) = Δg_i · w′(t)
f″(x) = Δg_i · w″(t)
```

二维是两个一维核的张量积（双线性组合），`f_xx / f_yy` 的跳变由对应轴核的 `w″` 端点决定，混合偏导 `f_xy` 含 `w′(t_x)w′(t_y)`，结论与一维完全相同，下文只证一维。

格点 `i` 处：左单元以 `t→1⁻` 到达，右单元以 `t→0⁺` 到达。

## 证明一：三次核只在格点处 C¹ 连续，二阶导跳变就是核端点导数差

三次核（Hermite smoothstep）：

```
w₃(t) = 3t² − 2t³
w₃′(t) = 6t(1−t)      →  w₃′(0)=0,  w₃′(1)=0
w₃″(t) = 6 − 12t      →  w₃″(0)=+6, w₃″(1)=−6
```

**函数连续**：`f(i⁻)=g_{i-1}+Δg_{i-1}·w₃(1)=g_i`，`f(i⁺)=g_i+Δg_i·w₃(0)=g_i`。

**一阶导连续（C¹）**：

```
f′(i⁻) = Δg_{i-1}·w₃′(1) = 0
f′(i⁺) = Δg_i·w₃′(0)    = 0
```

两侧都为零，与格点高差无关，故一阶导连续。

**二阶导跳变（一般不为零）**：

```
f″(i⁻) = Δg_{i-1}·w₃″(1) = −6·Δg_{i-1}
f″(i⁺) = Δg_i·w₃″(0)    = +6·Δg_i

J_i = f″(i⁺) − f″(i⁻) = w₃″(0)·Δg_i − w₃″(1)·Δg_{i-1}
                       = 6(Δg_i + Δg_{i-1})
```

即**跳变完全由核在端点的二阶导差 `w″(0)−w″(1)=12` 驱动**。只要相邻单元的格点高差非零，`J_i` 一般就非零；高差随机时 `J_i` 在每个格点周期性复现，这就是地形"棱"的来源。

> 测试对应：`internal/noise/noise_test.go::TestLatticeOneSidedDerivatives`
> 用解析导数核对恒等式 `J = w″(0)Δg_i − w″(1)Δg_{i-1}`（容差 1e-12），
> 并用单侧有限差分做同量级定性复核。

## 证明二：五次核让二阶导也连续（C²），跳变消失的条件

五次核（Perlin 改进噪声核）：

```
w₅(t) = 6t⁵ − 15t⁴ + 10t³
w₅′(t) = 30t²(1−t)²          →  w₅′(0)=w₅′(1)=0
w₅″(t) = 60t(1−t)(1−2t)      →  w₅″(0)=w₅″(1)=0
```

代入格点单侧极限：

```
f′(i⁻) = Δg_{i-1}·w₅′(1) = 0 = Δg_i·w₅′(0) = f′(i⁺)
f″(i⁻) = Δg_{i-1}·w₅″(1) = 0
f″(i⁺) = Δg_i·w₅″(0)    = 0
J_i = 0  （与格点高差无关）
```

故函数、一阶导、二阶导在格点处全部连续，即 C²。

### 跳变消失的条件

对任意核，格点 C² 的一般条件是

```
w(0)=0, w(1)=1            // 插值，保证函数连续
w′(0)=w′(1)=0             // C¹，且令两侧一阶导都归零
w″(0)=w″(1)               // C² 的必要条件
```

而跳变的通式是 `J_i = w″(0)Δg_i − w″(1)Δg_{i-1}`。由于随机格点的 `Δg_i`、`Δg_{i-1}` 可独立取任意值，要让 `J_i` 对**任意**高差恒为零，必须

```
w″(0) = w″(1) = 0
```

（仅 `w″(0)=w″(1)=c≠0` 时 `J_i=c(Δg_i−Δg_{i-1})` 一般仍非零。）五次核恰好满足这一充分且对随机格点必要的条件。

> 测试对应：`TestKernelEndpointDerivatives` 单独验证两种核的端点导数；
> 五次核的 `w₅″(0)=w₅″(1)=0` 以 1e-12 容差断言。

## 格点两侧一阶差分相等

两种核都有 `w′(0)=w′(1)=0`，故格点处单侧一阶导都为零。对有限步长 `h`，记左差分 `D⁻=f(i)−f(i−h)`、右差分 `D⁺=f(i+h)−f(i)`，泰勒展开：

```
D⁺ = h·f′(i⁺) + h²/2·f″(i⁺) + O(h³) = h²/2·w″(0)·Δg_i + O(h³)
D⁻ = h·f′(i⁻) − h²/2·f″(i⁻) + O(h³) = −h²/2·w″(1)·Δg_{i-1} + O(h³)
```

两者都趋于同一极限 0，差异为 O(h²)（三次核系数上界 12h²，五次核 2h²）。

> 测试对应：`TestFirstDifferenceAcrossLattice`，在 h=1e-2/1e-3/1e-4 三档下
> 断言差异满足 O(h²) 上界并随 h 收敛。

## 三档频率 × 两种核的对照实验

命令：`go run ./cmd/jumplab --size 256 --seed 7 --outdir artifacts/jumplab`

像素域跳变 `J_pix` 定义为格线两侧单侧二阶差分之差，采样步长 1 像素，
每格点像素数 `δ=1/freq`。解析缩放律：

```
三次核：J_pix ≈ J_物理 · δ²/4        （J_物理 与频率无关）→ J_pix·δ² 近似常数
五次核：物理跳变为 0，仅剩截断项 O(δ⁻³) → J_pix·δ³ 近似常数，J_pix·δ² 随 δ 增大趋于 0
```

### 跳变量与核类型（两栏）

| 频率 freq | δ(像素) | 核 | J_pix 均方根 | J_pix·δ²（物理跳变） | J_pix·δ³（截断律） | 格点/背景 梯度二阶差分均值比 |
|---|---|---|---|---|---|---|
| 0.01  | 100 | cubic   | 3.79e-04 | **3.79** | 379.1 | **20.99** |
| 0.01  | 100 | quintic | 3.82e-05 | 0.38 | **38.2** | 1.48 |
| 0.025 | 40  | cubic   | 2.90e-03 | **4.65** | 185.9 | **8.14** |
| 0.025 | 40  | quintic | 7.21e-04 | 1.15 | **46.1** | 1.93 |
| 0.05  | 20  | cubic   | 1.06e-02 | **4.23** | 84.6 | **3.86** |
| 0.05  | 20  | quintic | 5.05e-03 | 2.02 | **40.4** | 1.78 |

结论：

1. **三次核 `J_pix·δ²` 在三档频率下为 3.79 / 4.65 / 4.23，近似常数**，证明物理跳变客观存在、与采样频率无关，只由格点高差决定；波动来自 256 像素内格点样本较少（2/6/12 条缝）。
2. **五次核 `J_pix·δ³` 为 38.2 / 46.1 / 40.4，近似常数**，残差严格符合 δ⁻³ 截断律；其 `J_pix·δ²` 随 δ 增大（0.38→1.15→2.02 反向看 δ=100 时最小）趋于零，物理跳变消失。
3. **梯度图二阶差分的周期跳变**：三次核格点像素的均值是背景的 3.9～21 倍，系统性尖峰；五次核降到 1.48～1.93，不再有显著离群。五次核未严格到 1.0 是像素离散化下单元固有曲率的背景效应（五次核 `w⁗` 非零），硬判据是上面第 2 条的物理跳变趋于零。
