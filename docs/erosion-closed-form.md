# 降雨侵蚀单步式与总侵蚀闭式证明

## 1. 记号

对每个格子 \(i\)，在某一轮侵蚀计算前已经由地形和汇流关系得到：

- \(S_i\)：沿最陡下坡方向的坡度；
- \(Q_i\)：汇流量（本仓库的核对程序取 D8 上游格数，含本格）；
- \(K\)：降雨/抗侵蚀综合系数，闭式和迭代必须使用同一个值；
- \(e_i\)：单步侵蚀深度；
- \(E_i^{(N)}\)：\(N\) 轮后的累计侵蚀深度。

八位灰度高度图把 \([0,1]\) 分为 255 个灰度档距，因此一档灰度对应

\[
\Delta g_{\text{height}}=\frac{1}{255}.
\]

## 2. 单步侵蚀量是乘积闭式

题目采用的降雨侵蚀定率为线性流功率形式：

\[
e_i = KQ_iS_i.
\]

在常见的流功率公式 \(KQ^mS^n\) 中，这对应 \(m=n=1\)；降雨强度、岩性、可蚀性、单位换算等常数均可并入 \(K\)。因此，只要 \(Q_i,S_i\) 已给定，单步侵蚀量不需要迭代求解，它就是坡度、流量和系数三者的乘积。

代码入口：`internal/erosion.StepAmount`。

## 3. \(N\) 轮总量的闭式与归纳证明

以下结论针对同一份给定且各轮复用的 \(Q_i,S_i\)。迭代更新为

\[
h_i^{(t+1)}=h_i^{(t)}-KQ_iS_i,
\qquad
E_i^{(t)}=h_i^{(0)}-h_i^{(t)}.
\]

等价地，

\[
E_i^{(0)}=0,\qquad
E_i^{(t+1)}=E_i^{(t)}+KQ_iS_i.
\]

证明：

- 当 \(t=0\) 时，\(E_i^{(0)}=0=0KQ_iS_i\)。
- 假设第 \(t\) 轮有 \(E_i^{(t)}=tKQ_iS_i\)，则

\[
E_i^{(t+1)}
=E_i^{(t)}+KQ_iS_i
=tKQ_iS_i+KQ_iS_i
=(t+1)KQ_iS_i.
\]

由数学归纳法，对任意非负整数 \(N\)，

\[
\boxed{E_i^{(N)}=NKQ_iS_i}.
\]

所以高程可一次算出：

\[
\boxed{h_i^{(N)}=h_i^{(0)}-NKQ_iS_i}.
\]

实数运算下该式与逐步迭代完全相等；Go 的 `float64` 累加顺序不同会产生机器舍入差。

## 4. 逐格核对口径

运行：

```sh
make verify-erosion
```

程序用 `size=128 seed=7 octaves=4` 的同一张初始地形，构造一次 D8 坡度/汇流场，并固定 `K=2e-5`。闭式路径和迭代路径都把这同一个 `K` 作为入参，不存在分别调参或事后拟合。

选择两个轮数 \(N=16,64\)，结果列在同一组表中。主判据为

\[
255\left|h_{i,\mathrm{closed}}^{(N)}-h_{i,\mathrm{iter}}^{(N)}\right|>1,
\]

即连续高度差严格超过一档灰度宽度 \(1/255\)。同时报告四舍五入后的整数灰度码差是否大于 1，避免把取整边界上的 1 码差异误读成超过一档。

当前确定性运行结果：

| 轮数 \(N\) | 格数 | 超一档灰度格数 | 灰度码差 >1 | 最大灰度距离 |
|---:|---:|---:|---:|---:|
| 16 | 16384 | 0 | 0 | \(2.26\times10^{-13}\) 档 |
| 64 | 16384 | 0 | 0 | \(9.06\times10^{-13}\) 档 |

完整逐格数据是 `artifacts/erosion/r016_cell_comparison.csv` 和 `r064_cell_comparison.csv`；汇总为 `artifacts/erosion/report.json` / `report.md`。

## 5. 图件存档

`artifacts/erosion/` 中为每个轮数分别保存：

- `height_before.pgm/.png`：侵蚀前高程；
- `r016_height_after_closed.*`、`r016_height_after_iter.*`：闭式和迭代的侵蚀后高程；
- `r016_height_difference_before_minus_after_closed.*`、`..._iter.*`：两条路径各自的侵蚀前后高差；
- `..._difference_..._stretch.*`：仅用于观察空间结构的线性拉伸图，定量判据不使用拉伸后灰度；
- `r016_mismatch_over_one_gray_bin.*`：超过一档灰度的违规格掩膜，当前全黑；
- `r064_*`：第二轮数对应的同一组图件和 CSV。

PGM 是定量八位灰度；PNG 只是便于直接查看的同款预览。

## 6. 适用边界

上面的严格等式证明的是“给定坡度与汇流量”且在重复计算中复用该场的代数迭代。若实现每轮后都重新计算 \(S_i^{(t)}\) 或 \(Q_i^{(t)}\)，递推变为

\[
E_i^{(N)}=K\sum_{t=0}^{N-1}Q_i^{(t)}S_i^{(t)},
\]

此时 \(NKQ_i^{(0)}S_i^{(0)}\) 一般只是小侵蚀量近似，不是完整动态地貌模型的闭式解。题目要求证明的乘积式和一次总量式对应前一种、也是调参时可直接向量化的固定场计算。
