# 冲沟核心格：双阈值合取判定、侵蚀前预判与逐格核对证明

本文证明题目要求的两件事，并给出在确定性地形上的全量逐格验证：

1. 冲沟（核心格 + 沟岸宽度）必出现在“汇流累积超阈值 **且** 坡度超阈值”的格子及其八邻域附近；核心格判定写成两个阈值的合取。
2. 仅凭侵蚀前初始高程即可预判全部冲沟核心格的坐标与八邻域连通段条数；在给定检测杠与参数区间内，该预判集合与侵蚀后用前后高程差逐格统计出的核心格集合严格相等。

实现：`internal/hydro`（D8 流向/坡度/汇流）、`internal/gully`（合取、八邻域分量、阈值门控侵蚀、逐格比对）、`cmd/gully`（一次跑出全部产物）。复现：

```bash
go test ./...          # 含端到端“零不一致”断言
go run ./cmd/gully     # 生成 artifacts/gully/ 全部报告、CSV 与两张标注图
```

实验地形固定为 `size=128 seed=7 octaves=4 lacunarity=2 gain=0.5 frequency=0.02`，共 `N=16384` 格。

---

## 1. 记号与离散规则

- 格点 `c=(x,y)`，索引 `i=yN+x`，坐标原点在画幅左上角。
- D8 方向固定编号 `E,SE,S,SW,W,NW,N,NE`；邻格距离 `L_d=1`（正向）或 `√2`（斜向）。
- 离散坡度：

\[
S(c)=\max_{d:\,h(c)>h(n_d)}\frac{h(c)-h(n_d)}{L_d}
\]

只接受严格更低的邻格；等坡并列取方向编号最小者，保证可复算。无严格下坡邻格时 `Recv=-1`（洼地/平地/边界终点，不填洼）。

- 汇流累积 `A(c)`：每格初始贡献 1，按高程降序把本格累积量加到唯一接收格。因为每条流向边严格下降，流向图是 DAG，降序结算一次即正确，`A(c)` 含本格。

## 2. 核心格判定：两个阈值的合取

取 `τ_A=32`、`τ_S=0.030`（约 `1.72°`），判定式只有一个入口（`gully.CoreMask`）：

\[
\boxed{\operatorname{Core}(c)=\bigl[A(c)>\tau_A\bigr]\ \land\ \bigl[S(c)>\tau_S\bigr]}
\]

严格不等号；`A=32` 或 `S=0.030` 的格子不入选。两个条件缺一不可：谷宽水缓处（累积大、坡度小）与孤立陡坡（坡度大、汇流小）都不是核心格。本地形该判定给出 **69 个核心格**。

## 3. 命题一：冲沟必出现在合取格附近

**侵蚀模型（阈值启动的下切 + 一圈沟岸拓宽，单场事件内 A、S 场冻结）：**

\[
\operatorname{CoreCut}(c)=
\begin{cases}
\sum_{r=1}^{R}K\,D(c),&\operatorname{Core}(c)=1\\
0,&\operatorname{Core}(c)=0
\end{cases}
\]

\[
D(c)=\sqrt{\min(A(c)/\tau_A,8)\,\min(S(c)/\tau_S,8)}
\]

沟岸拓宽 `BankCut(c)` 只可能发给与核心格八邻域相邻的非核心格，且 `0≤BankCut(c)≤B_g`（强度相关上限）。于是按作用域直接有：

\[
\{c:\operatorname{Cut}(c)>0\}
\subseteq \operatorname{Core}\cup N_8(\operatorname{Core})
=\operatorname{Dilate}_8(\operatorname{Core},1)
\]

即：**任何被侵蚀到的格子，要么本身就是双阈值合取格，要么在某个合取格的八邻域一圈之内（切比雪夫距离 ≤ 1）。** 这就是“冲沟必出现在……格子附近”的精确离散表述，“附近”= 八邻域半径 1。

逐格核验（`gully.NearCheck`）：两组强度下全部 16384 格无一例外，半径 1 带外的受侵蚀格均为 **0**；弱/强组分别有 292 个沟岸格实际发生拓宽，说明该包含不是空命题。

## 4. 命题二：侵蚀前可预判位置与连通段条数

### 4.1 可预判性

`A(c)`、`S(c)` 都只是初始高程场 `H₀` 的函数，在任何侵蚀轮次之前由 `hydro.Build(H₀)` 一次算出，与强度 `K` 无关。因此

\[
\operatorname{Core}_0=\{c:[A_0(c)>\tau_A]\land[S_0(c)>\tau_S]\}
\]

及其八邻域连通段划分，在“未跑完整侵蚀”甚至未跑任何侵蚀步时就已唯一确定。八邻域连通段由行优先扫描 + BFS（邻向按固定 8 方向顺序）得到，段号按首次出现顺序编号，结果确定可复算。本地形为 **25 段**，各段格数见 `artifacts/gully/segments8.csv`。

### 4.2 预判集合与侵蚀后实测集合相等

侵蚀后**不读预判掩膜**，只从前后高程差定义逐格统计的实测核心格：

\[
\operatorname{Meas}(c)=[\operatorname{Cut}(c)\ge D_{\rm core}],\qquad D_{\rm core}=0.005
\]

两组参数：弱 `K=0.0015`、强 `K=0.0045`，均 `R=10` 轮；沟岸上限分别 `B_{\rm weak}=0.0012`、`B_{\rm strong}=0.0030`。

**方向一：`Core₀ ⊆ Meas`。** 核心格上 `A>32`（整数故 `A/32≥33/32>1`）且 `S/0.03>1`，所以 `D(c)>1`。弱组单格累计核心下切严格大于

\[
R K_{\rm weak}=10\times0.0015=0.015>0.005=D_{\rm core}
\]

（3 倍余量），强组为其 3 倍，同样过杠。即便极端情况下下切撞到高程下限 `Floor=0`，核心格仍有 `h₀(c) > τ_S·1 = 0.03 > D_core`：因为它存在一个坡度 `>τ_S` 的严格更低邻格，而邻格高程 `≥0`。本次运行也确实 `floorClipped=0`，实测最大下切弱 `0.04914`、强 `0.14741`，核心格初始最低高程 `0.189`。

**方向二：`Meas ⊆ Core₀`。** 非核心格核心下切恒为 0；其可能得到的全部侵蚀量就是沟岸拓宽，而

\[
\operatorname{Cut}(c)\le B_g\le 0.0030<0.005=D_{\rm core}
\]

故永远过不了实测核心检测杠（撞底截断只会让实际深度更小，不破坏结论）。

两向包含成立，故 **`Meas = Core₀`**。连通段是掩膜的函数，集合逐格相等则八邻域段数、段划分逐格相等。

### 4.3 全量逐格比对（不只靠证明）

`cmd/gully` 对全部 16384 格逐格比较预判位与实测位，分为：

- `missing`：预判核心、实测不是；
- `extra`：实测核心、预判不是。

两组结果均为 `missing=0, extra=0`，段号划分逐格相同。任何不一致格都会把坐标 `(x,y)`（及 `index=yN+x`、类别、下切深度）写入：

- `artifacts/gully/mismatch_coordinates_<weak|strong>.txt`
- `artifacts/gully/mismatches_<weak|strong>.csv`

本次两份坐标文件均明确写着“不一致格：无”（CSV 只有表头）。全格数据在 `comparison_<weak|strong>.csv`（16384 行，含 `acc,slope,pred_core,segment8_pred,cut,meas_core,segment8_meas,match`），可用任意表格工具独立复核；已用独立脚本核验该 CSV 中 `match` 列全为 1、预判/实测各 25 段且段划分零差异。

## 5. 两组强度结果（核心格数、连通段条数各占一行）

| 指标 | 弱强度组 K=0.0015 | 高强度组 K=0.0045 |
|---|---:|---:|
| 核心格数 | 69 | 69 |
| 连通段条数（八邻域） | 25 | 25 |

强度改变的是下切深度与总侵蚀量（总下切量 1.795 vs 5.268），不改变合取确定的核心位置与段数——这正是可预判性的实际含义。每组一张冲沟标注图：`artifacts/冲沟标注图_弱强度组.png`、`artifacts/冲沟标注图_高强度组.png`（另存 ASCII 文件名与 `artifacts/gully/annotation_<weak|strong>.png`）。红块为核心格，橙点为沟岸/八邻域影响带，`#编号` 为八邻域段号。

## 6. 适用边界（如实声明）

1. 零不一致结论针对**阈值启动、单场事件内冻结 A、S 场**的侵蚀模型。若每轮后重算 D8 汇流/坡度，下切可能抬高局部坡度差、使新格过阈，此时 `Core₀` 与最终核心不必相等，必须把场更新规则纳入递推另行证明。
2. “附近”的半径 1 来自本模型的一圈沟岸规则；加入长距离搬运、滑坡或冲积扇后需放大半径并重新核验包含式。
3. 所有判定在 float64 上进行；PGM 为 8 位量化，近阈值坡度可能因量化翻转，独立复算请用 `height_before.f64` / `height_after_<g>.f64`（小端 float64，长度 `N²`）或直接重跑命令。
4. 阈值是对该 seed/尺寸地形选定的演示参数；换地形后格数、段数会变，判定与核对流程不变。
