# 高度分布的解析近似与分位预判

结论：归一化之前的 fBm 高度近似服从正态分布，其方差只由**谱斜率（gain）与层数（octaves）**
决定（其余因子是插值核与值表的常数）。因此任意分位 q 的高度有显式近似式

```
h(q) ≈ σ_F · Φ⁻¹(q)
```

无需生成地形即可预判。推导如下，验证见 `cmd/quantile`。

## 1. 模型与符号

流水线（`api.Generate`，归一化之前）：

```
F(x) = ( Σ_{k=0..N-1} g^k · n(x·f0·L^k) ) / S1,   S1 = Σ g^k = (1-g^N)/(1-g)
```

- `n` 为值噪声（`internal/noise`）：格点值经五次 fade 双线性插值；
- `g` = gain，`L` = lacunarity，`N` = octaves，`f0` = frequency。

**谱斜率 ↔ gain**：第 k 层振幅 A_k = g^k = (f0·L^k)^(−α)，其中 α = ln(1/g)/ln L。
即 gain 就是振幅谱斜率的参数化（默认 L=2、g=0.5 对应 α=1，功率谱 ∝ 1/f²）。
"由谱斜率与层数决定" 即 "由 (g, N) 决定"。

## 2. 引理 1（单层方差是核常数）

值表是 0..255 的置换（`noise.New`），故格点值 h = k/127.5 − 1 的边际**精确**均匀
分布于 256 个离散值，均值 0，方差

```
σ_h² = (1/256)·Σ_{k=0..255} (k/127.5 − 1)² = (256²−1)/(12·127.5²) = 4369/13005 ≈ 0.335948
```

插值值是四角值的加权和 n = Σ w_i·c_i，权重只依赖格内坐标 (u,v) = (fade(fx), fade(fy))。
假设 **H1**：四角值近似独立。则

```
Var(n) = σ_h² · E[Σ w_i²]
E[Σ w_i²] = ( E[u²] + E[(1-u)²] )² = ( 2∫₀¹ fade(t)² dt )²
∫₀¹ (6t⁵−15t⁴+10t³)² dt = 36/11 − 18 + 345/9 − 75/2 + 100/7 = 181/462
⇒ E[Σ w_i²] = (181/231)² ≈ 0.613950
σ_oct²  = σ_h² · (181/231)² ≈ 0.206255        （核常数，与地形无关）
```

## 3. 引理 2（层间方差可加）

假设 **H2**：不同频率的层在空域上近似不相关（同一置换表经哈希寻址，层间互相关 ≈ 0，
由实测验证）。各层均值都是 0，于是

```
Var(F) = σ_oct² · Σ g^{2k} / S1² = σ_oct² · S2 / S1²,   S2 = (1-g^{2N})/(1-g²)
```

## 4. 定理（分布近似只含谱斜率与层数）

每层噪声有界（|n| ≤ 1）且对称，加权和满足 Lyapunov 条件，由中心极限定理
F 近似正态；N 有限时这是近似，残余偏差主要在尾部。即

```
F ≈ N(0, σ_F²),   σ_F² = σ_oct² · (1-g^{2N})(1-g)² / ( (1-g²)(1-g^N)² )
```

右端只含 (g, N) 与核常数 σ_oct²。∎

默认参数（g=0.5, N=4）：S1 = 1.875，S2 = 1.328125，**σ_F ≈ 0.279140**。

## 5. 分位显式式与可预判性

```
h(q) ≈ σ_F · Φ⁻¹(q)
```

**可预判性（构造性证明）**：σ_oct² 是值表与 fade 核的定积分（常数，§2 已算出）；
S1、S2 是 (g, N) 的显式函数；Φ⁻¹ 是确定函数（Acklam 有理逼近误差 ~1e-9）。
式中没有任何随机量或需要采样估计的量，故任意 q 的分位高度无需生成地形、
无需统计即可求值。∎

默认参数下：

| q | Φ⁻¹(q) | 预判 h(q) |
|---|---------|-----------|
| 0.10 | −1.281552 | ≈ −0.35773 |
| 0.50 | 0 | 0 |
| 0.90 | +1.281552 | ≈ +0.35773 |

## 6. 近似的边界（诚实声明）

- H1、H2 是假设，N=4 时高斯近似在尾部有残余偏差——必须靠实测量化，见验证工具。
- `hmap.Normalize` 的 min-max 归一化是仿射变换，保分位序：归一化分位 =
  (h(q) − min)/(max − min)。但 min/max 是随实现（种子、尺寸）变化的极值，
  **不**只由 (g, N) 决定，故定理针对归一化前的原始高度；归一化分位须用实测
  min/max 做仿射换算。
- 单张地图是相关随机场的一次实现：有效样本数约为 n_eff ≈ (size·f0)²
  （方差主导层第 0 层的独立格数），实测分位的统计标准误约为
  se(q) ≈ σ_F·√(q(1−q)/n_eff) / φ(Φ⁻¹(q))。报告偏差时必须同时给出采样数，
  以免统计误差被误读为近似偏差。

## 7. 验证

`cmd/quantile` 按 §5 的显式式预判，生成同参数原始高度场实测分位，逐档比对，
尾部（一成、九成）偏差单独列出，预判与实测累计分布图分别存档。
