# fBm 高度图坡度分布：从谱斜率到最大坡度预判

本文证明三层结论并给出可复算的预判公式，实验对照由 `cmd/slopeat` 生成
（`artifacts/slope/report.md`）。

## 0. 记号

- 网格边长 S，总格数 N = S²，层数 K；基础频率 f₀（周/像素），频率倍增 ℓ = 2，
  增益 g = 1/2；第 i 层振幅 a_i = g^i，频率 f_i = f₀ℓ^i，归一化系数 A_K = Σa_i。
- 值噪声 n(x) = Σ_j c_j·w(x − j)，角点值 c_j 独立同分布（置换表是 0..255 的
  均匀置换，c = h/127.5 − 1），E[c] = 0，σ_c² = (256²−1)/12/127.5² ≈ 0.33595。
- 插值核可分离：w(x,y) = φ(x)φ(y)，φ 是五次 fade 对应的一维核。
- 坡度角约定：tanθ = |∇h|，垂直单位 = 整个归一化值域，水平单位 = 1 像素。

## 1. 命题 1：单层梯度分布由谱斜率近似给出

**命题.** 单层值噪声的梯度分量 ∂ₓn 渐近服从 N(0, σ_1²)，其中 σ_1² 是噪声功率谱的
二阶矩；若谱在有效频带上服从幂律 P(f) ∝ |f|^(−β)（β 即谱斜率），则 σ_1² 由
β、谱幅与频带完全确定。

**证明.**

*(i) 渐近正态性.* ∂ₓn(x) = Σ_j c_j·∂ₓw(x − j) 是有界独立随机变量的线性组合。
由平移不变性，权重平方和 Σ_j (∂ₓw(x−j))² 是不依赖 x 的常数（对格点平均
E_x[Σ_j ψ(x−j)²] = ∫ψ²du），且每个权重一致小（|∂ₓw| ≤ max|φ′| 有界、核紧支撑），
Lindeberg 条件成立，由中心极限定理 ∂ₓn 渐近正态。∎(i)

*(ii) 方差 = 谱二阶矩.* n 平稳，功率谱 P_n(f) = σ_c²|W(f)|²（W 为核 w 的傅里叶
变换）。微分在频域乘以 2πif_x，故梯度谱 P_∂(f) = (2πf_x)²P_n(f)，

  σ_1² = ∫ (2πf_x)² P_n(f) df.

若 P_n(f) ≈ P₀|f|^(−β) 于频带 [f_a, f_b]，则

  σ_1² ≈ (2π)²P₀ · [f^(3−β)/(3−β)]_{f_a}^{f_b}   (β ≠ 3)。

即谱斜率 β、谱幅 P₀、频带三者唯一确定梯度分布 N(0, σ_1²)。∎(ii)

**闭式校准.** 对本仓库的五次 fade 核，σ_1² 可精确积出。记
u = fade(f_x)，v = fade(f_y)，则 ∂ₓn = u′·[(1−v)(c₁₀−c₀₀) + v(c₁₁−c₀₁)]，
角点差独立、方差 2σ_c²，故

  σ_1² = E[u′²]·2σ_c²·E[(1−v)²+v²] = (20/7)·σ_c²·m₂ ≈ 0.7521，

其中 E[u′²] = ∫₀¹[30t²(1−t)²]²dt = 900·B(5,5) = 10/7（两侧瓣合计 20/7），
m₂ = E[(1−v)²+v²] = 181/231 ≈ 0.78355（E[v] = 1/2，E[v²] = 181/462 均为
多项式精确积分）。σ_1 ≈ 0.8672（每格），与 `TestSingleLayerSigma` 的实测
偏差 < 3%。

**中心差分修正.** 实测坡度用中心差分 Δw = [w(·+1) − w(·−1)]/2，对应把解析
梯度的核换成差分核。频率 f（周/像素）处的核能量

  D(f) = ∫ [(φ(u+f) − φ(u−f))/2]² du，  f→0 时 D(f) → f²·20/7，

由数值积分精确求得（`FDKernelEnergy`）。f 超过 Nyquist（0.5 周/像素）后，
该积分自动包含混叠——这是 K ≥ 6 时预判仍准确的关键（见 §5）。

## 2. 命题 2：多层梯度之和的合成分布

**命题.** K 层 fBm 的梯度分量渐近服从 N(0, σ_K²)，
σ_K² = σ_c²·Φ₂·Σ_i a_i²D(f_i)/A_K²（Φ₂ = ∫φ² = m₂）；两分量独立，
故模长 |∇z| 服从 Rayleigh(σ_K)。

**证明.**

*(i) 层间独立性.* 第 i 层在物理点 x 的梯度只依赖角点 {⌊f_i x⌋ 附近}。
两层共享同一角点当且仅当 f_i x 与 f_j x 同时落在同一整数格点上，即
(f_j − f_i)x ∈ Z——测度为零的相位点集。故在几乎每一点，各层梯度依赖的
角点集合互不相交，由角点独立性，各层梯度分量在几乎处处意义下相互独立。
（同一角点值会出现在不同层的*不同*物理位置，这只造成场与场的整体重排
相关，不改变同一点的边际分布。）

*(ii) 合成.* 第 i 层对 x 的梯度为 a_i·∇n(f_i x)，由命题 1 渐近正态、方差
a_i²σ_c²Φ₂D(f_i)。独立正态之和仍正态，方差相加；除以 A_K 得

  σ_K² = σ_c²·Φ₂·Σ_i a_i²D(f_i) / A_K²。  ∎(ii)

*(iii) 模长.* 由核的可分离对称性 E[∂ₓn·∂_y n] = 0（关于 y 的奇对称），
两分量不相关；联合正态下不相关即独立。故 |∇z| = √(G_x²+G_y²) 服从
Rayleigh(σ_K)：

  p(g) = (g/σ_K²)·exp(−g²/2σ_K²)，  P(G > g) = exp(−g²/2σ_K²)。  ∎(iii)

**归一化修正.** 导出图 h = (z − z_min)/R，R = z_max − z_min 是随机变量。
用期望近似：E[R] ≈ 2σ_z·√(2 ln N_eff)，其中
σ_z = σ_c·Φ₂·√(Σa_i²)/A_K 是高度值标准差，N_eff = (S·f₀)² 是基频格数
（高度方差由低频层主导，极值的有效独立样本数由基频格距决定）。
归一化图的梯度参数 s_K = σ_K/E[R]。

## 3. 命题 3：最大坡度的期望由上分位给出

**命题.** 设 G_1..G_N 为坡度样本（近似独立），M = max G_i，F 为边际分布。
则 E[M] 由重现格数 R 对应的上分位 g_R = F⁻¹(1 − 1/R) 在 R = N 处逼近，
相对误差 O(1/ln N)。取重现格数

  **R(N, K) = N/1000**

（总格数的千分之一；R 与 K 无关是设计选择——分位深度固定才能跨层比较，
K 只通过 s_K 进入预判值），得最大坡度预判

  tan θ̂_max = s_K·√(2 ln(N/1000))，  θ̂_max = atan(s_K·√(2 ln(N/1000)))。

**证明.** P(M ≤ g) = F(g)^N，故

  E[M] = ∫₀^∞ (1 − F(g)^N) dg。

对 Rayleigh 尾 1 − F(g) = exp(−g²/2s²)：代入 u = g²/2s²，被积函数
1 − (1 − e^(−u))^N 在 u ≈ ln N 附近从 1 跳到 0（Gumbel 极限），
标准的极值展开给出

  E[M] = s·√(2 ln N)·[1 + γ/(2 ln N) + O(1/ln²N)]，

γ 为欧拉常数。而 R = N 的分位正是 g_N = s√(2 ln N)，故 E[M] = g_N·(1 +
O(1/ln N))。∎

取 R = N/1000 而非 R = N 是有意的稳健化：该分位对应每图约 1000 个超越
样本，其经验估计的涨落远小于逐图最大值（后者对应 R ≈ N，且受归一化
极差 R 的逐图随机性放大）。实验同时报告两者（report.md 的"实测真极值"
列），可以看到真极值系统性高于 N/1000 分位约 √（ln N / ln(N/1000)) ≈ 1.5
倍，与上式一致。

**30° 超越占比.** 由命题 2(iii)，P(θ > 30°) = exp(−tan²30°/(2s_K²))。

## 5. 偏差超过两成的层数：K=1（−35%）

K=1 是唯一偏差超过 20% 的层数，原因有两个，都出在"单层"上：

1. **高度场有界，高斯极差公式失效。** 单层值噪声逐点有界 |z| ≤ 1，
   极差硬上界为 2。高斯场近似给出 E[R] = 2σ_z√(2 ln N_eff) = 2.771，
   超过硬上界；实测 E[R] = 1.983，已贴近 2（105 个基频格内角点值的
   最大值逼近 ±1）。极差被高估 40%，s_1 同比例被低估。
2. **梯度尾部比 Rayleigh 轻。** 单层梯度 u′·[(1−v)D₁+vD₂] 只是两个
   均匀差加权和乘有界因子，支撑有界（|∂ₓn| ≤ 1.875×2），不满足 CLT
   的"许多分量"条件；其高分位低于同方差正态/Rayleigh 的预测。

K ≥ 2 起多层求和使 CLT 生效（命题 2），两个误差同时快速消退：K=2 偏差
已落到 −12.3%，K ≥ 4 在 5% 以内。K = 6..8 的最高层频率 0.64/1.28/2.56
周/像素已超 Nyquist，但核能量 D(f) 的积分定义自动计入了混叠，预判不
退化——这验证了命题 1 中"分布由谱（含混叠后的实测谱）给出"的表述。

**关于 30° 占比恒为 0.** 本生成器 f₀ = 0.02、垂直单位取整个值域时，
s_K ≈ 0.006–0.012，tan30° = 0.577 对应 48–92 倍标准差，超越概率低于
10⁻¹⁰⁰⁰，预判与实测同为 0。框架对垂直比例是协变的：若地形另有垂直
比例 z（每单位值域对应 z 个水平像素单位的高度），把 s_K 换成 z·s_K 即可；
例如要使 30° 超越占比达到 0.1%，需要 z ≈ tan30°/(s_K√(2 ln 1000)) ≈
20/s_K 量级，即垂直比例放大约 2–3 个数量级。
