# 洼地个数 ＝ 未被溢流覆盖的极小点数：深度阈值免迭代预判与逐格比对

本文回答四件事：

1. 证明**填洼后剩余洼地数 ＝ 未被溢流覆盖的四邻域局部极小点数**，并把该数与洼地深度阈值 τ 直接联系；
2. 证明**只凭原始灰度场算一次溢流深度，就能按 τ 预判剩余洼地的个数与坐标，无需迭代填洼**；
3. 给出两档 τ 的“一行一档”结果，并把预判坐标与填洼后逐格扫描坐标**逐个配对比对**，`d∞>1` 格的标出；
4. 如实记录一个连通性口径现象：若溢流按 D8（八邻域）走，完整填洼后会恰好残留 3 个四邻域极小。

所有数字由 `analysis/depressions.py` 产出、`cmd/depverify`（Go）独立复核，
原始结论见 `artifacts/depression_result.json`、`artifacts/depression_go_verify.json`、
`artifacts/depression_rows.md`、`artifacts/depression_compare.csv`。

## 1. 约定（口径先钉死）

- 数据：README 示例的规范地形 `--size 128 --seed 7 --octaves 4`
  （`Frequency=0.02` 是 `cmd/goproc` 内定值），导出为 8-bit PGM，灰度 `G∈{0,…,255}`。
  本文所有“深度”都是**灰度差**（多少个灰度级），不涉及物理高程单位。
- 坐标 `(x,y)` 为格网 0 基下标，`x` 向右、`y` 向下。
- **洼地 ＝ 内部四邻域严格局部极小**：`1≤x,y<N−1` 且
  `G(y,x)` 严格小于上、下、左、右四个正交邻格。边界格没有四个邻格，
  且水到画幅边缘即出流，按出口处理，不计入。
  - 采用“严格”是必要的：若改成“小于等于四邻”，同一张图会数出 **301** 个平台格，
    那不是洼地个数。严格定义下全图共 **21** 个。
- 格偏差用切比雪夫距离 **`d∞=max(|dx|,|dy|)`（格）**：`d∞≤1` 即落在同一环（3×3）内，
  **`d∞>1` 判为超格并标出**；同时报告欧氏距离备查。

### 1.1 溢流高程 S 与洼地深度 Δ

对每格定义 minimax 溢流高程（多源 Dijkstra / Priority-Flood 一次求出，边界格以自身灰度为源）：

\[
S(c)=\min_{p:\,c\to\partial\Omega}\ \max_{z\in p} G(z),
\]

即“从 c 走到边界，沿途必须越过的最高灰度”的最小值。它正是无 ε 的**完整填洼面**。

极小点 m 的洼地（夺顶）深度取

\[
\Delta(m)=S(m)-G(m)\quad\text{（灰度级）}.
\]

注意这**不是**“最低邻格−本格”的一阶切口深度。本图 21 个极小的一阶切口深度**全部为 1**
（量化微坑，正是肉眼找不到的原因），无法分档；真正区分洼地规模的是到溢流口的完整深度 Δ，
其降序为

```
107, 57, 55, 53, 52, 52, 37, 32, 10, 9, 9, 6, 6, 3, 2, 2, 1, 1, 1, 1, 1
```

### 1.2 深度阈值 τ 与“溢流覆盖”的含义

τ 是允许填充的最大深度（灰度级）。定义**限深填洼面**

\[
F_\tau(c)=\min\bigl(S(c),\,G(c)+\tau\bigr),
\]

即每格相对原始灰度最多抬 τ 级。称极小 m **被（阈值内）溢流覆盖**，是指 τ 足以把它
“夺顶/填到溢流面”从而使它不再是严格极小，判据正是 `Δ(m)≤τ`；反之 `Δ(m)>τ` 为**未被覆盖**。

> 术语澄清：`Δ(m)>τ` 的深洼，其坑底在限深填洼中仍会被回水压高 τ 级
> （`Fτ(m)=G(m)+τ>G(m)`），所以若把“覆盖”理解成“沾到一点水/被抬过”，深洼也算被覆盖。
> 本文的“溢流覆盖”特指**淹没至溢流口 S、把该极小作为洼地消除**（hydrologically topped）。
> 若要一个逐格的二元覆盖掩码，可取
> `Kτ={c: S(c)−G(c)≤τ}`（被一口气填到溢流面的格子），对极小 m 有
> `m∉Kτ ⇔ Δ(m)>τ`，于是“未被溢流覆盖”在字面上也成立。

## 2. 证明一：剩余洼地数 ＝ 未被溢流覆盖的局部极小数

记 `M=Min4(G)` 为原场四邻域严格极小集合。先给 minimax 面的相邻不等式：
对任意正交相邻格 a,b，a 可以先走到 b 再沿 b 的最优路径出边，故

\[
S(a)\le \max\bigl(G(a),S(b)\bigr). \tag{1}
\]

**引理 A（填后不会冒出新的严格极小）**：`Min4(Fτ) ⊆ M`。

*证明*：反设 `z∈Min4(Fτ)` 但 `z∉M`。因 z 不是原场严格极小，存在邻格 u 使 `G(u)≤G(z)`。
又 `S(z)≥G(z)≥G(u)`，对 u 用 (1)（u 经 z 出边）：

\[
S(u)\le\max(G(u),S(z))=S(z).
\]

同时 `G(u)+τ≤G(z)+τ`。于是

\[
Fτ(u)=\min(S(u),G(u)+τ)\le \min(S(z),G(z)+τ)=Fτ(z),
\]

这与 z 是 `Fτ` 的严格极小（应 `Fτ(z)<Fτ(u)`）矛盾。∎

**引理 B（每个原极小按 Δ 决定存亡，且坐标不变）**：对 `m∈M`，

\[
m\in Min4(Fτ)\ \Longleftrightarrow\ \Delta(m)>\tau,
\]

并且存活时仍是**同一坐标**的严格极小。

*证明*：严格极小 + 整数量化给出每个邻格 u 满足 `G(u)≥G(m)+1`；且第一步就必须踏上更高邻格，
故 `S(m)>G(m)`。对 m 用 (1)：`S(m)≤max(G(m),S(u))`，左侧 `S(m)>G(m)`，因此 `S(u)≥S(m)`。

- 若 `Δ(m)>τ`，则 `S(m)>G(m)+τ`，故 `Fτ(m)=G(m)+τ`。对任一邻格 u：
  `G(u)+τ≥G(m)+1+τ>Fτ(m)`，且
  `S(u)≥S(m)=G(m)+Δ(m)>G(m)+τ=Fτ(m)`。
  两者都严格大于 `Fτ(m)`，所以 `Fτ(u)=min(...)>Fτ(m)`，m 在原坐标仍是严格极小。
- 若 `Δ(m)≤τ`，则 `Fτ(m)=S(m)`。Dijkstra 松弛树上存在一个把 S(m) 松弛下来的邻格 p，
  满足 `S(m)=max(G(m),S(p))`，从而 `S(p)≤S(m)`。于是
  `Fτ(p)≤S(p)≤S(m)=Fτ(m)`，m 不再严格低于 p，即被覆盖消除。∎

**定理一（个数恒等式）**：由引理 A、B，作为坐标集合

\[
\boxed{\,Min4(Fτ)=\{\,m\in M:\Delta(m)>\tau\,\}=M\setminus Cτ\,}
\]

其中 `Cτ={m∈M:Δ(m)≤τ}` 是被溢流覆盖的极小集合。因此

\[
\boxed{\ N_{\text{剩余}}(τ)=|Min4(Fτ)|=|M\setminus Cτ|
=\#\{\,m\in M:\Delta(m)>\tau\,\}. \ }
\]

这正是“剩余洼地个数等于未被溢流覆盖的局部极小点个数”，并把它与深度阈值直接联系起来：
**阈值越高（允许填得越深），剩余数单调不增**，是 Δ 经验分布上的一级级阶梯。

## 3. 证明二：按深度阈值免迭代预判个数与位置

`S` 只需在**原始 G** 上用一个优先队列（多源 Dijkstra / Priority-Flood）算一次，
复杂度 `O(N² log N)`；随后对任意 τ：

\[
Pτ=\{\,(x,y)\in M:\ S(y,x)-G(y,x)>\tau\,\}
\]

就是预判的剩余洼地位置，`|Pτ|` 是预判个数。**不需要**“抬一格→重新扫极小→再抬”的迭代循环，
换 τ 只是对已算好的 Δ 做一次比较过滤。由定理一，`Pτ` 与实际限深填洼后逐格扫描集合逐点相同。

> 与“迭代填洼”的关系：朴素的“把严格极小抬到最低邻格、反复扫描直到无洼”收敛到完整填洼面 S。
> 在本图上，因 21 个坑的一阶切口深度全为 1，同步一轮就把严格极小清零；
> 完整 4 邻域填洼（`τ=∞, F=S`）后实测剩余 **0** 个。所以题头“填洼后还剩几个”
> 不是“完整填洼没填干净”，而是**只给了有限填深预算 τ 时，Δ>τ 的深洼留下来了**。

1. Python 在 **τ=0…107 每一档**重算 Fτ 并逐格扫描，集合恒等且史上最大偏差 `allTauWorstCheb=0`
   （写入 JSON `allTauIdentityOK=true`）；
2. Go 对同一份 PGM 独立实现 Minima4/Spill/FillLimited/Compare，τ=20/40 坐标完全一致，
   且在 `12/20/33` 边长、多个确定性种子的随机网格上对所有 τ 跑恒等式测试，全部通过；
3. “超一格标记”本身有正/反自测：Python `flagSelfTest` 构造 `(10,10)→(12,10)` 得 `d∞=2`
   并正确置 `over1=true`；Go `TestCompareFlagsOverOneCell` 同时验证 `d∞=2` 必标、
   `d∞=1`（对角相邻）不标、`d∞=0` 不标。

**如实说明**：在“四邻域严格极小 + 整数值溢流面 + 一致的四连通”口径下，引理 B 保证坐标恒等，
因此真实地形上不会出现 `d∞>1`；一格容差是为平台/量化/口径差异预留的。本数据两档的最大偏差是 0，
故图上没有琥珀色警示线——这是核验结果，不是漏标。

## 4. 连通性口径附注：完整 D8 填洼后为何还剩 3 个

题头“填洼之后还剩几个小洼地”在另一种常见口径下有更字面的对应。本仓库 `internal/flow`
的流向是 **D8（八邻域，并列取小编号）**。若溢流/填洼按 8 连通 minimax 面 `S8` 走完整填洼，
再按题目规定的**四邻域严格极小**检测 `S8`，会残留**恰好 3 个**：

| 坐标 | G | Δ4（四连通深度） | Δ8（八连通深度） | 对角出口 |
|---|---:|---:|---:|---|
| (7,55)  | 154 | 1 | 0 | 东北 (8,54)=154 等高 |
| (27,74) | 153 | 1 | 0 | 东北 (28,73)=153 等高 |
| (10,126)| 156 | 1 | 0 | 西南 (9,127)=155 更低 |

它们四个正交邻格都严格更高（故都是合法四邻域洼地、肉眼难辨的 1 级微坑），
但各有一个**对角**等/低邻格：D8 溢流认为水可沿对角排走，于是不抬升该格（Δ8=0），
而四邻域检测仍把它数成洼地。这正是“**未被（八向）溢流覆盖的四邻域局部极小**”。
三点坐标与原极小一致（`d∞=0`），所以这是**连通性口径差异**，不是深度阈值预判的位置误差；
若用四连通深度阈值，它们 Δ4 仅 1–2，在 τ=20/40 下本就属于“被覆盖”的浅坑。
该现象与第 2 节的四连通精确恒等式并存，区别只在溢流连通性，已写入 JSON `connectivityCaveat`。

## 6. 口径与局限清单

- “局部极小”取**内部、严格、四邻域**；非严格平台计数（301）不是本文对象。
- “深度”取到 minimax 溢流口的完整灰度差 Δ，而非一阶邻格差（后者全为 1，无法分档）。
- 主恒等式要求**溢流与判定使用同一四连通口径**；换 D8 会出现第 4 节的 3 个孤儿。
- 限深填洼面取 `Fτ=min(S,G+τ)`（每格封顶抬 τ 级）这一明确算子；
  其它“按盆地统一给深”的限深定义会改变中间格子，但极小点存亡判据仍是 Δ 与 τ 的比较。
- 结果绑定规范地形 128/seed7/o4；换种子/尺寸需重跑脚本，结论形式（定理）不变，数值会变。
